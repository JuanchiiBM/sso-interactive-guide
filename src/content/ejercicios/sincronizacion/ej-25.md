  solucion: |
    semaphore sem_artefactos_limite = LIMITE_SISTEMA, sem_encargo_entregado = 0, mutex_cola_sistema = 1;
    semaphore sem_seccion_limite[SECCIONES] = LIMITE_SECCION;
    semaphore sem_encargo_disponible[SECCIONES] = 0, mutex_seccion[SECCIONES] = 1;

    void Cliente() {
      while(1) {
        artefacto_roto = obtener_artefacto_roto(lista_artefactos_del_cliente);
        encargo = llevar_a_reparar(artefacto_roto);
        wait(sem_artefactos_limite);
        wait(mutex_cola_sistema);
        entregar_encargo(encargo, cola_sistema);
        signal(mutex_cola_sistema);
        signal(sem_encargo_entregado);
      }
    }

    void Administrador() {
      while(1) {
        wait(sem_encargo_entregado);
        wait(mutex_cola_sistema);
        encargo = retirar_encargo(cola_sistema);
        signal(mutex_cola_sistema);
        signal(sem_artefactos_limite);
        id_seccion = obtener_seccion_de(encargo);
        wait(sem_seccion_limite[id_seccion]);
        wait(mutex_seccion[id_seccion]);
        depositar(encargo, cola_encargos[id_seccion]);
        signal(mutex_seccion[id_seccion]);
        signal(sem_encargo_disponible[id_seccion]);
      }
    }

    void Tecnico() {
      while(1) {
        id_seccion = seccion_perteneciente(id_tecnico);
        wait(sem_encargo_disponible[id_seccion]);
        wait(mutex_seccion[id_seccion]);
        encargo = tomar_encargo(cola_encargos[id_seccion]);
        signal(mutex_seccion[id_seccion]);
        signal(sem_seccion_limite[id_seccion]);
        reparar_artefacto(encargo);
      }
    }
  justificacion: |
    Dos **productor-consumidor con buffer acotado** en cadena: clientes → cola del sistema → administrador,
    y administrador → cola de cada sección → técnico. El segundo es **por sección**, así que va con arrays
    de semáforos indexados por `id_seccion`:

    | Semáforo | Tipo | Inicial | Para qué |
    | -------- | ---- | ------- | -------- |
    | `sem_artefactos_limite` | contador | 50 | lugares libres en la cola del sistema |
    | `sem_encargo_entregado` | contador | 0 | el administrador espera que haya un encargo |
    | `mutex_cola_sistema` | mutex | 1 | la cola del sistema es compartida |
    | `sem_seccion_limite[5]` | contador por sección | 10 | lugares libres en cada sección |
    | `sem_encargo_disponible[5]` | contador por sección | 0 | el técnico espera un encargo de **su** sección |
    | `mutex_seccion[5]` | mutex por sección | 1 | la cola de cada sección es compartida |

    - `signal(sem_artefactos_limite)` va apenas el administrador **retira** el encargo: el lugar en la
      cola del sistema ya se liberó, aunque todavía no lo haya depositado en una sección.
    - El administrador puede quedar esperando lugar en una sección llena: eso no es deadlock, porque el
      técnico de esa sección sigue tomando encargos y hace el `signal(sem_seccion_limite[id_seccion])`.
    - Un solo contador para todas las secciones no sirve: el técnico de la sección 1 podría "consumir"
      el aviso de un encargo que quedó en la sección 0.
---

Existe un centro de reparación de computadoras, donde nos ofrecen varios servicios, como formateo, reparación, etc.; siendo cada uno de ellos una sección del comercio.

El centro acepta tener **hasta 50 trabajos pendientes** en la cola de su sistema. El cliente lleva el artefacto a reparar y se le asigna un encargo, el cual es ingresado en la cola del sistema. Luego, el administrador es quien los asigna a las distintas secciones de reparación. El lugar disponible **por sección es de 10 encargos**.

Teniendo en cuenta el pseudocódigo presentado, sincronice utilizando únicamente semáforos.

**Nota:** la variable `id_seccion` puede tomar valores desde 0 a 4.

while(1) {

**Administrador (1 instancia)**

**Técnico (5 instancias)**
