    codigo: |
      while(TRUE){

  - nombre: C

        print("C");
      }
  acciones:

  tests:
  - tipo: secuencia
    acciones:
    - print("A")
    - print("B")
    - print("C")
  - tipo: sin-deadlock
  - tipo: todas-ejecutan
  solucion: |
    semaphore sa = 1, sb = 0, sc = 0;

    void A() {
      while(TRUE){
        wait(sa);
        print("A");
        signal(sb);
      }
    }

    void B() {
      while(TRUE){
        wait(sb);
        print("B");
        signal(sc);
      }
    }

    void C() {
      while(TRUE){
        wait(sc);
        print("C");
        signal(sa);
      }
    }
  justificacion: |
    Misma idea que A-B, extendida a un anillo: cada proceso espera su semáforo y habilita al siguiente
    (A → B → C → A). Solo el primero de la secuencia arranca en 1; el resto en 0.
