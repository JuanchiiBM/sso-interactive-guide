Dados los siguientes procesos, sincronícelos para ayudar a la scaloneta con el entrenamiento! Cada vez que De Paul agarra una pelota, debe pasársela al capitán para que él concrete la jugada. Indique qué tipo de semáforo empleó para su solución.

<div class="codigo-columnas">

**De Paul**

```c
while(TRUE){
  agarra_pelota();
  se_la_paso_messi();
}
```

**Messi**

```c
while(TRUE){
  recibe_pelota();
  patea_al_arco();
}
```
