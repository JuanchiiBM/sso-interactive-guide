      while(TRUE){
        posicionarse();
        signal(clienteEnCola);
        wait(atendido);
        hacerPedido();
        signal(pedidoRealizado);
        wait(pedidoListo[id()]);
        retirarHelado();
      }
    }

    void Cajero() {
      while(true) {
        wait(clienteEnCola);
        llamarCliente();
        signal(atendido);
        wait(pedidoRealizado);
        pedido = tomarPedido();
        wait(mutexPedidos);
        agregar(pedidos, pedido);
        signal(mutexPedidos);
        signal(pedidosPendientes);
      }
    }

    void Heladero() {
      while(true) {
        wait(pedidosPendientes);
        wait(mutexPedidos);
        pedido = retirar(pedidos);
        signal(mutexPedidos);
        idSabor = pedido->sabor;
        wait(contadorSabores[idSabor]);
        entregarHelado();
        idCliente = pedido->cliente;
        signal(pedidoListo[idCliente]);
      }
    }

    void Fabrica() {

        entregarHelado();
        signal(contadorSabores[0]);
        signal(contadorSabores[1]);
        signal(contadorSabores[2]);
        esperarDosHoras();
      }
    }

    | `atendido` | contador | 0 | el cliente espera que lo llamen |

      al cliente dueño del pedido (`pedido->cliente`), no al primero que esté esperando.
    - En la resolución de la cátedra la fábrica hace `signal(contadorSabores[i]) x50` por cada sabor: 50
      paletas de cada uno por entrega.
---

Parranui SA quiere sincronizar su sistema de venta de paletas de helado. Los clientes llegan al local y se posicionan en la cola para hacer su pedido. El cajero los llama **en orden de llegada** para que hagan su pedido. Una vez realizado el pedido, el cajero toma nota del mismo y se lo pasa al heladero.

El heladero retira **cualquiera** de los pedidos pendientes (no necesariamente por orden de llegada) y lo entrega al respectivo cliente **sí y sólo sí posee stock del sabor** de helado especificado. Caso contrario, espera a tener paletas de ese sabor para hacer la entrega. Se sabe que el sector de Fábrica de Parranui SA entrega, cada dos horas, **50 paletas de cada uno de los 3 sabores** disponibles: frutilla, vainilla y chocolate (representados por los id 0, 1 y 2 respectivamente) y que **se comienza sin stock**.

**Notas:** el tipo de dato `pedido` es una estructura que contiene los datos `sabor` (id del sabor pedido por el cliente) y `cliente` (id del cliente). Cliente posee una función `id()` que devuelve su propio id.

Variable compartida: `pedidos`
