- etiqueta: a. 3 recursos con M instancias
  nota: |
    `pedir_recurso()` devuelve el **id** de un recurso al azar (0 a 3-1): los tests prueban todos los valores posibles en cada vuelta. Podés usar la constante `M` (para correr los tests **M = 2**) y arrays de semáforos: `semaphore s[N] = valor;` y `wait(s[id_recurso]);`.
  procesos:
  - nombre: Proceso
    instancias: 3
    codigo: |
      while(TRUE){
        id_recurso = pedir_recurso();
        usar_recurso(id_recurso);
      }
  locales:
  - id_recurso
  constantes:
    M: 2
  acciones:
    id_recurso = pedir_recurso():
      asigna:
        variables:
        - id_recurso
        valores: 3
    usar_recurso(id_recurso):
      recursos:
      - recurso[id_recurso]
  tests:
  - tipo: capacidad
    recurso: recurso[*]
    max: 2
    nombre: Nunca hay más de 2 usando un mismo recurso
  - tipo: capacidad-alcanzable
    recurso: recurso[*]
    valor: 2
    nombre: Se pueden usar las 2 instancias de un recurso a la vez
  - tipo: sin-deadlock
  - tipo: todas-ejecutan
  solucion: |
    semaphore recursos[3] = M;

    void Proceso() {
      while(TRUE){
        id_recurso = pedir_recurso();
        wait(recursos[id_recurso]);
        usar_recurso(id_recurso);
        signal(recursos[id_recurso]);
      }
    }
  justificacion: |
    Cada recurso distinto es un conjunto de **M instancias idénticas**: un **semáforo contador por recurso**
    inicializado en M. Como el recurso lo decide `pedir_recurso()` en cada vuelta, se usa un **array de
    semáforos** indexado por el id (regla de la cátedra: si hay un "id" de recursos, un array de semáforos).

    - Tipo: contador (uno por recurso), valor inicial M.
    - `wait` y `signal` tienen que ir sobre **el mismo** `recursos[id_recurso]`.
    - Un solo contador en 3·M para todo no alcanza: dejaría pasar más de M procesos al mismo recurso.

Dado un sistema con N procesos del mismo programa, sincronice su código mediante semáforos para respetar los siguientes límites:

- a. 3 recursos distintos con M instancias de cada uno
- b. M recursos distintos con 3 instancias de cada uno

**Proceso A**

```c
while(TRUE){
  id_recurso = pedir_recurso();
  usar_recurso(id_recurso);
}
```
