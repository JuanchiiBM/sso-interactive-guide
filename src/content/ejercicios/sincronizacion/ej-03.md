semaforos:
- procesos:
  - nombre: Proceso
    instancias: 4
    codigo: |
      while(TRUE){
        preparar_documento();
        usar_impresora();
        continuar_trabajando();
      }
  acciones:
    preparar_documento(): {}
    usar_impresora():
      recursos:
      - impresora
    continuar_trabajando(): {}
  tests:
  - tipo: capacidad
    recurso: impresora
    max: 3
    nombre: Nunca se usan más de 3 impresoras
  - tipo: capacidad-alcanzable
    recurso: impresora
    valor: 3
    nombre: Se pueden usar las 3 impresoras a la vez
  - tipo: sin-deadlock
  - tipo: todas-ejecutan
  solucion: |
    semaphore impresoras = 3;

    void Proceso() {
      while(TRUE){
        preparar_documento();
        wait(impresoras);
        usar_impresora();
        signal(impresoras);
        continuar_trabajando();
      }
    }
  justificacion: |
    Hay **3 instancias idénticas** de un recurso: se usa un **semáforo contador** inicializado en la
    cantidad de instancias (**3**). Cada `wait` toma una impresora; cuando las tres están en uso el valor
    llega a 0 y el cuarto proceso se bloquea hasta que alguien haga `signal`.

    - Tipo: **contador** (general), valor inicial 3.
    - Un mutex (valor 1) también evita pasarse de 3, pero desperdicia dos impresoras: por eso existe el
      test "se pueden usar las 3 a la vez".
    - `preparar_documento()` y `continuar_trabajando()` quedan **afuera**: no usan la impresora.
---

Dado un sistema con N procesos, se dispone de un conjunto de tres impresoras idénticas. Cada proceso necesita utilizar una impresora para imprimir un documento. Sincronice el siguiente código mediante semáforos para garantizar que nunca se utilicen más impresoras de las disponibles.
_Indique cada tipo de semáforo empleado para su solución._

**Proceso (N instancias)**

```c
while(TRUE){
  preparar_documento();
  usar_impresora();
  continuar_trabajando();
}
```
