    | Regla                                              | Semáforo                    | Inicial      |

    | Patean en orden (jug1, jug2, …)                    | `turno[N]`, uno por jugador | `{1, 0, …}`  |

    El **orden de los pateadores** sale del array `turno`: cada jugador espera **su** posición

    Solo un jugador está activo por vez, por eso `orden`, `pateo` y `resultado_jugador` pueden ser
    semáforos simples.

    `posicionados` se espera **dos veces** porque tienen que estar listos el jugador **y** el arquero,
    en cualquier orden.
---

Se tiene un programa para simular la ejecución de penales de cierta final del mundo en Qatar 2022, el cual consta de tres procesos: árbitro, jugador y arquero. El pseudocódigo es el siguiente:

<div class="codigo-columnas">

**Árbitro**

```c
while(TRUE){
  dar_orden();
  validar_tiro();
}
```

**Jugador**

```c
while(TRUE){
  posicionarse();
  patear();
  if (GOL==TRUE){
    festejar();
  }else{
    lamentarse();
  }
}
```

**Arquero**

```c
while(TRUE){
  posicionarse();
  atajar();
  if (GOL==FALSE){
    festejar();
  }else{
    lamentarse();
  }
}
```

</div>

Las reglas que debe cumplir son las siguientes:

- ✓ Existen cinco procesos jugadores, un proceso árbitro y un proceso arquero.
- ✓ Los jugadores no pueden patear si el árbitro no lo indicó.
- ✓ El arquero no puede atajar si el jugador no pateó.
- ✓ El árbitro sólo puede dar la orden cuando el jugador y el arquero están posicionados.
- ✓ Existe una variable global GOL, la cual es modificada por la función `validar_tiro()`, que indica si el último penal pateado fue gol o no.
- ✓ Una vez que se valide el penal, se le pasará el turno al próximo jugador.
- ✓ Los jugadores siempre patean en un orden definido (ej: jug1, jug2, …, jug5, jug1, jug2, etc). Existe a disposición la función `actual()` que retorna el id del pateador actual, y la función `siguiente()` que retorna el id del próximo pateador.

Provea una solución que sincronice los tres procesos usando solamente semáforos, asegurándose que se cumplan las reglas establecidas sin producirse deadlock ni starvation. Se deberá inicializar cada semáforo, indicando también su tipo.
