  justificacion: |
    Son **dos errores del mismo tipo**, uno en cada productor-consumidor: el `wait(mutexMostrador)` va
    **antes** del semáforo contador.

    - **Maestro pizzero:** si el mostrador está lleno, se bloquea en `wait(hayLugarEnMostrador)` **con el
      mutex tomado**. Las motos, para sacar pizzas y liberar lugar, necesitan ese mutex → deadlock.
    - **Moto delivery:** si no hay pizzas, se bloquea en `wait(hayPizzas)` **con el mutex tomado**. Los
      pizzeros, para dejar una pizza, necesitan ese mutex → deadlock.

    La corrección es invertir el orden en los dos: primero el contador ("¿hay lugar?" / "¿hay pizzas?"),
    después el mutex.

La pizzería "La Nonna" ofrece delivery a sus clientes. Los maestros pizzeros amasan y cocinan pizzas de forma continua, depositándolas en el mostrador a medida que están listas. El mostrador tiene capacidad para almacenar **hasta 50 cajas de pizza**. Los empleados del área de delivery retiran las pizzas del mostrador para entregarlas a sus respectivos clientes.

a) Identifique los errores que tuvo el dueño de la pizzería al sincronizar a sus empleados.

b) Suponiendo que el pseudocódigo no tuviera errores de sincronización, inicialice los semáforos correctamente.

**Maestro pizzero (M instancias)**

```c
while(1) {
  pizza = amasarYCocinar();
  wait(mutexMostrador);
  wait(hayLugarEnMostrador);
  dejarEnMostrador(mostrador, pizza);
  signal(mutexMostrador);
  signal(hayPizzas);
}
```

**Moto delivery (N instancias)**

```c
while(1) {
  wait(mutexMostrador);
  wait(hayPizzas);
  pizza = sacarDelMostrador(mostrador);
  signal(mutexMostrador);
  signal(hayLugarEnMostrador);
  viajar();
  signal(timbre[obtenerIdCliente()]);
}
```

**Cliente (K instancias)**

```c
wait(timbre[id()]);
pizza = recibirPizza();
comer(pizza);
```
