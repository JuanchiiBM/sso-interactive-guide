- etiqueta: a. Con 4 semáforos
  procesos:
  - nombre: A
    instancias: 1
    codigo: |
      while(TRUE){
        print("A");
      }
  - nombre: B
    instancias: 1
    codigo: |
      while(TRUE){
        print("B");
      }
  - nombre: C
    instancias: 1
    codigo: |
      while(TRUE){
        print("C");
      }
  acciones:
    print("A"): {}
    print("B"): {}
    print("C"): {}
  tests:
  - tipo: secuencia
    acciones:
    - print("B")
    - print("A")
    - print("C")
    - print("A")
  - tipo: sin-deadlock
  - tipo: todas-ejecutan
  - tipo: max-semaforos
    max: 4
  solucion: |
    semaphore sa = 0, sb = 1, sc = 0, fin_a = 0;

    void A() {
      while(TRUE){
        wait(sa);
        print("A");
        signal(fin_a);
      }
    }

    void B() {
      while(TRUE){
        wait(sb);
        print("B");
        signal(sa);
        wait(fin_a);
        signal(sc);
      }
    }

    void C() {
      while(TRUE){
        wait(sc);
        print("C");
        signal(sa);
        wait(fin_a);
        signal(sb);
      }
    }
  justificacion: |
    El problema es que **A imprime dos veces por ciclo** y su código es el mismo en cada vuelta: A no
    puede saber si después le toca a C o a B. Entonces A solo avisa "terminé" (`fin_a`) y **quien lo
    habilitó decide quién sigue**:

    - B imprime, habilita a A, espera `fin_a` y recién ahí habilita a C.
    - C imprime, habilita a A, espera `fin_a` y habilita a B.

    Solo `sb` arranca en 1 porque la secuencia empieza con B.
- etiqueta: b. Con 3 semáforos
  procesos:

      while(TRUE){

      }
  - nombre: B
    instancias: 1
    codigo: |
      while(TRUE){
        print("B");
      }
  - nombre: C
    instancias: 1
    codigo: |
      while(TRUE){
        print("C");
      }
  acciones:
    print("A"): {}
    print("B"): {}
    print("C"): {}
  tests:
  - tipo: secuencia
    acciones:
    - print("B")
    - print("A")
    - print("C")
    - print("A")
  - tipo: sin-deadlock
  - tipo: todas-ejecutan
  - tipo: max-semaforos
    max: 3
  solucion: |
    semaphore sa = 0, sb = 1, sc = 0;

    void A() {
      while(TRUE){
        wait(sa);
        print("A");
        signal(sc);
      }
    }

    void B() {
      while(TRUE){
        wait(sb);
        print("B");
        signal(sa);
      }
    }

    void C() {
      while(TRUE){
        wait(sc);
        print("C");
        signal(sa);
        wait(sc);
        signal(sb);
      }
    }
  justificacion: |
    Se reutiliza `sc` para las dos cosas que necesita C: A **siempre** hace `signal(sc)` después de
    imprimir, y C lo consume de dos formas distintas según el momento:

    1. La A que sigue a B despierta a C en su primer `wait(sc)`: C imprime y habilita a A.
    2. La A que sigue a C despierta a C en su **segundo** `wait(sc)`: C no imprime, solo habilita a B.

    Así A no necesita saber quién sigue, y alcanza con 3 semáforos.
