        wait(reporte_publicado[id_especialidad]);

    void Recolector() {
      while(1) {
        muestra = recolectar_muestra();
        wait(limite_repositorio);
        wait(mutex_muestra);
        depositar(muestra, repositorio_muestras);
        signal(mutex_muestra);
        signal(muestra_disponible);
      }
    }

        wait(muestra_disponible);
        wait(mutex_muestra);
        muestra = retirar_muestra(repositorio_muestras);
        signal(mutex_muestra);
        signal(limite_repositorio);
        procesar_muestra(muestra);
        publicar_reporte();
        signal(reporte_publicado[0]);
        signal(reporte_publicado[1]);
        signal(reporte_publicado[2]);
      }
    }
  justificacion: |
    Un **productor-consumidor con buffer acotado** (recolectores → repositorio → bioquímica) y un
    **aviso a cada analista** por cada reporte publicado:

    | Semáforo | Tipo | Inicial | Para qué |
    | -------- | ---- | ------- | -------- |
    | `limite_repositorio` | contador | 20 | lugares libres en el repositorio |
    | `muestra_disponible` | contador | 0 | la bioquímica espera que haya una muestra |
    | `mutex_muestra` | mutex | 1 | el repositorio es compartido |
    | `reporte_publicado[3]` | contador por analista | 0 | cada analista espera **su** aviso |

    - Hace falta **un semáforo por analista**: con uno solo y tres `signal`, un analista rápido podría
      consumir dos avisos del mismo reporte y otro analista se quedaría sin revisarlo. Así no se cumple
      que "todas las muestras sean analizadas por los 3".
    - Los `signal(reporte_publicado[i])` van **después** de `publicar_reporte()`: antes, un analista
      podría revisar un reporte que todavía no existe.
    - `revisar_reporte()` no necesita mutex: los analistas solo leen el reporte.

En un laboratorio donde trabaja 1 revolucionaria bioquímica, se intenta recrear la estructura de ciertas proteínas. Se tienen N recolectores que se encargan de hacer el trabajo de campo buscando muestras de diversos seres vivos. Los mismos cuentan con un **repositorio con capacidad para 20 muestras**. La bioquímica luego las procesa y envía su reporte a los analistas.

Existen **3 analistas**, cada uno con una especialidad particular, que deben revisar el reporte de la bioquímica y sacar sus conclusiones en base a su especialidad. Es fundamental que **las muestras sean analizadas por los 3 analistas**.

**Nota:** `getIdEspecialidad()` devuelve el id del analista (0, 1 o 2).

<div class="codigo-columnas">

**Analista (3 instancias)**

```c
while(1) {
  id_especialidad = getIdEspecialidad();
  revisar_reporte();
}
```

**Recolector de muestras (N instancias)**

```c
while(1) {
  muestra = recolectar_muestra();
  depositar(muestra, repositorio_muestras);
}
```

**Bioquímica (1 instancia)**

```c
while(1) {
  muestra = retirar_muestra(repositorio_muestras);
  procesar_muestra(muestra);
  publicar_reporte();
}
```
