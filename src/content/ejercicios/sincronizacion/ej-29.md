    Dos **productor-consumidor** encadenados (clientes → pendientes → procesador → validados → baristas)

    | Semáforo | Tipo | Inicial | Para qué |
    | -------- | ---- | ------- | -------- |
    | `capacidadPreparador` | contador | 50 | máximo de pedidos pendientes |
    | `preparador` | contador | 0 | el procesador espera un pedido pendiente |
    | `mutexPendientes`, `mutexValidados` | mutex | 1 | cada lista es compartida |
    | `semValidados` | contador | 0 | los baristas esperan un pedido validado |
    | `tomarCafe[N]` | contador por cliente | 0 | cada cliente espera **su** café |

    - El aviso va indexado por `cafe.idCliente`: los baristas trabajan en paralelo y pueden terminar en
      cualquier orden, así que con un solo semáforo un cliente podría llevarse el café de otro.
    - El cliente espera con `getId()`, su propio id: es la otra punta del mismo aviso.
    - `signal(capacidadPreparador)` lo hace el procesador al **retirar** el pedido, no al validarlo: ahí es
      cuando se libera el lugar en pendientes.
---

En una cafetería autónoma, tres robots baristas (R2-D2, Wall-E y C-3PO) y un robot procesador trabajan en equipo para servir pedidos. Los clientes realizan pedidos de café mediante una app móvil y luego esperan a recibir su café.

El robot procesador recibe los pedidos pendientes, los valida y los deja listos para ser preparados. Luego, los robots baristas se encargan de retirar los pedidos validados, hacer el café y **avisarle a su respectivo cliente** que el mismo está listo. Además, el robot procesador soporta un **máximo de 50 pedidos pendientes** en un mismo instante.

Sincronice el siguiente pseudocódigo utilizando semáforos para que cumpla con lo pedido, sin generar deadlocks ni starvation.

Variables compartidas: `pendientes`, `validados`

**Notas:** la variable `cafe` tiene un atributo `cafe.idCliente` que contiene el id del cliente que pidió ese café. El proceso Cliente tiene una función `getId()` que devuelve su propio id.

<div class="codigo-columnas">

**Cliente (N instancias)**

```c
while(true) {
  pedido = generarPedido();
  agregar(pedido, pendientes);
  tomarCafe();
}
```

**Procesador (1 instancia)**

```c
while(true) {
  pedido = retirar(pendientes);
  validar(pedido);
  agregar(pedido, validados);
}
```

**Robot barista (3 instancias)**

```c
while(true) {
  pedido = retirar(validados);
  cafe = hacerCafe(pedido);
  servir(cafe);
}
```
