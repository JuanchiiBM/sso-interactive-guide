nota: |
  **Recurso que otorga otro proceso (pedido y respuesta)**: el avión no toma la pista por su cuenta. Se
  la **pide** a la controladora de entrada, que se la **otorga**, y al terminar de usarla le **avisa** a
  la controladora de salida. Cada una de esas interacciones es una sincronización de **orden** entre
  dos procesos, y la de entrada va en los **dos sentidos**: la controladora tiene que esperar a que haya
  un pedido, y el avión tiene que esperar a que se la otorguen antes de usarla. **Sin inanición una vez
  pedida**: alcanza con que la cola de bloqueados de cada semáforo se atienda en **FIFO** (la
  convención de la cátedra), porque el primero que se bloquea es el primero en despertar.

- nota: |
    Para correr los tests se usan **2 aviones** y **1 pista**: la constante `PISTAS` vale 1 y `pistasLibres` arranca en 1 (en el enunciado son 10).
  procesos:

  constantes:
    PISTAS: 1
  variables:
    pistasLibres: 1
    otorgadas: 0
    enUso: 0
  acciones:
    mantenimiento(): {}

    volar(): {}
    aterrizar():
      efecto:

      efecto:
        pistasLibres: -1

        pistasLibres: 1
  tests:
  - tipo: rango
    variable: otorgadas
    min: 0
    nombre: Ningún avión despega o aterriza sin una pista otorgada
    motivo: "Hay una intercalación en la que un avión despega o aterriza sin que la controladora le haya otorgado una pista."
  - tipo: rango
    variable: enUso
    min: 0
    max: 1
    nombre: Nunca se otorgan más pistas de las que hay ni se libera una que no estaba en uso
    motivo: "Hay una intercalación en la que se otorga una pista cuando no queda ninguna libre, o se libera una que nadie estaba usando."
  - tipo: rango
    variable: pistasLibres
    min: 0
    nombre: pistasLibres nunca queda negativa
    motivo: "Hay una intercalación en la que pistasLibres queda negativa."
  - tipo: exclusion
    recurso: pistasLibres
    nombre: Mutua exclusión sobre pistasLibres (y su log)
  - tipo: sin-deadlock
  - tipo: todas-ejecutan
  solucion: |
    semaphore pedido = 0, otorgada = 0, liberada = 0, pistas = PISTAS, mutex = 1;

    void Avion() {
      while(TRUE){
        mantenimiento();
        signal(pedido);
        wait(otorgada);
        despegar();
        signal(liberada);
        volar();
        signal(pedido);
        wait(otorgada);
        aterrizar();
        signal(liberada);
      }
    }

    void Controladora_Entrada() {
      while(TRUE){
        wait(pedido);
        wait(pistas);
        otorgarUnaPista();
        wait(mutex);
        pistasLibres--;
        log(pistasLibres);
        signal(mutex);
        signal(otorgada);
      }
    }

    void Controladora_Salida() {
      while(TRUE){
        wait(liberada);
        liberarUnaPista();
        wait(mutex);
        pistasLibres++;
        log(pistasLibres);
        signal(mutex);
        signal(pistas);
      }
    }
  justificacion: |
    Hay tres "conversaciones" entre procesos y un recurso con instancias:

    | Semáforo   | Tipo     | Inicial | Para qué                                                          |
    | ---------- | -------- | ------- | ----------------------------------------------------------------- |
    | `pedido`   | contador | 0       | el avión avisa a la controladora de entrada que quiere una pista  |
    | `otorgada` | contador | 0       | la controladora le avisa al avión que ya tiene pista              |
    | `liberada` | contador | 0       | el avión avisa a la controladora de salida que terminó            |
    | `pistas`   | contador | 10      | la entrada no otorga si no quedan pistas libres                   |
    | `mutex`    | mutex    | 1       | `pistasLibres` la modifican las dos controladoras (con su `log`)  |

    El avión **pide y espera** antes de despegar y antes de aterrizar, y avisa al terminar de usar la
    pista. La controladora de entrada **espera un pedido y una pista libre**; la de salida devuelve la pista
    al contador `pistas` después de actualizar la variable.

Existe un aeropuerto que se utiliza como base de operaciones de una flota de aviones.

- ✓ Existen muchos aviones, diez pistas de aterrizaje / despegue y dos controladores aéreos.
- ✓ Cada vez que un avión desea despegar o aterrizar, debe utilizar una pista. Para ello, la misma es solicitada al controlador de entrada, y luego de ser utilizada se le notifica al controlador de salida para que vuelva a estar disponible.

Se pide que sincronice el siguiente pseudo-código respetando las reglas establecidas, sin que se produzca deadlock ni starvation (cuando el avión ya pidió pista). Para ello solamente debe utilizar semáforos, indicando el tipo de los mismos y sus valores iniciales.

**Avión**

```c
while(TRUE){
  mantenimiento();
  despegar();
  volar();
  aterrizar();
}
```

`pistasLibres = 10; // variable compartida`

<div class="codigo-columnas">

**Controladora Entrada**

```c
while(TRUE){
  otorgarUnaPista();
  pistasLibres--;
  log(pistasLibres);
}
```

**Controladora Salida**

```c
while(TRUE){
  liberarUnaPista();
  pistasLibres++;
  log(pistasLibres);
}
```

</div>

Nota: La función `log()` imprime por pantalla el valor actual de pistas libres.
