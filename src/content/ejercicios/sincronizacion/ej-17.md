semaforos:
- nota: |
    Solo se completan los **valores iniciales**: los `wait`/`signal` quedan como están. `wait(s) x3` = tres `wait` seguidos.
  inicial: |
    semaphore sem_a = ?, sem_m = ?, sem_c = ?, sem_r = ?, sem_e = ?, sem_n = ?;
  soloInicializar: true
  procesos:
  - nombre: Hilo A
    instancias: 1
    codigo: |
      while(true){
        wait(sem_a);
        print("A");
        signal(sem_m);
        signal(sem_c);
        signal(sem_r);
      }
  - nombre: Hilo M
    instancias: 1
    codigo: |
      while(true){
        wait(sem_m) x3;
        print("M");
        signal(sem_a);
      }
  - nombre: Hilo C
    instancias: 1
    codigo: |
      while(true){
        wait(sem_c) x3;
        print("C");
        signal(sem_a);
      }
  - nombre: Hilo R
    instancias: 1
    codigo: |
      while(true){
        wait(sem_r) x3;
        print("R");
        signal(sem_e);
      }
  - nombre: Hilo E
    instancias: 1
    codigo: |
      while(true){
        wait(sem_e);
        print("E");
        signal(sem_n);
      }
  - nombre: Hilo N
    instancias: 1
    codigo: |
      while(true){
        wait(sem_n);
        print("N");
        signal(sem_a);
      }
  acciones:
    print("A"): {}
    print("M"): {}
    print("C"): {}
    print("R"): {}
    print("E"): {}
    print("N"): {}
  tests:
  - tipo: secuencia
    acciones:
    - print("M")
    - print("A")
    - print("C")
    - print("A")
    - print("R")
    - print("E")
    - print("N")
    - print("A")
    nombre: Se imprime MACARENA, en orden, para siempre
  - tipo: sin-deadlock
  solucion: |
    semaphore sem_a = 0, sem_m = 3, sem_c = 2, sem_r = 1, sem_e = 0, sem_n = 0;

    void Hilo_A() {
      while(true){
        wait(sem_a);
        print("A");
        signal(sem_m);
        signal(sem_c);
        signal(sem_r);
      }
    }

    void Hilo_M() {
      while(true){
        wait(sem_m) x3;
        print("M");
        signal(sem_a);
      }
    }

    void Hilo_C() {
      while(true){
        wait(sem_c) x3;
        print("C");
        signal(sem_a);
      }
    }

    void Hilo_R() {
      while(true){
        wait(sem_r) x3;
        print("R");
        signal(sem_e);
      }
    }

    void Hilo_E() {
      while(true){
        wait(sem_e);
        print("E");
        signal(sem_n);
      }
    }

    void Hilo_N() {
      while(true){
        wait(sem_n);
        print("N");
        signal(sem_a);
      }
    }
  justificacion: |
    La clave está en los `x3`: M, C y R necesitan **tres** permisos para imprimir, y cada A entrega **uno
    a cada uno**. Entonces el valor inicial de cada consonante es "cuántas A faltan para su turno":

    | Semáforo | Inicial | Por qué |
    | -------- | ------- | ------- |
    | `sem_m`  | 3       | M es la primera: arranca con los 3 permisos |
    | `sem_c`  | 2       | C va después de 1 A: le falta 1 permiso |
    | `sem_r`  | 1       | R va después de 2 A: le faltan 2 |
    | `sem_a`, `sem_e`, `sem_n` | 0 | los habilita la letra anterior |

    Traza del vector (a, m, c, r, e, n), tal como la muestra la resolución oficial:
    `(0,3,2,1,0,0)` → M → `(1,0,2,1,0,0)` → A → `(0,1,3,2,0,0)` → C → `(1,1,0,2,0,0)` → A →
    `(0,2,1,3,0,0)` → R → E → N → `(1,2,1,0,0,0)` → A → `(0,3,2,1,0,0)`: **vuelve al inicio**, así que
    MACARENA se repite.
