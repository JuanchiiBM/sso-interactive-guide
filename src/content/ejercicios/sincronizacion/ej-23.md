    semaphore mutexPedidos = 1, mutexValidados = 1;
    semaphore limitePedidos = LIMITE, pedidosPendientes = 0, valPendientes = 0;
    semaphore turnoLuciano = 3, turnoLeonardo = 0;

    void Usuario() {
      while(TRUE){
        diseño = crearDiseño();
        wait(limitePedidos);
        wait(mutexPedidos);
        agregar(diseño, pedidos);
        signal(mutexPedidos);
        signal(pedidosPendientes);
      }
    }

        wait(pedidosPendientes);
        wait(mutexPedidos);
        diseño = retirar(pedidos);
        signal(mutexPedidos);
        signal(limitePedidos);
        validar(diseño);
        wait(mutexValidados);
        agregar(diseño, validados);
        signal(mutexValidados);
        signal(valPendientes);
      }
    }

        wait(valPendientes);
        wait(mutexValidados);

        signal(mutexValidados);
        imprimir(diseño);
        signal(turnoLeonardo);
      }
    }

        signal(mutexValidados);
        imprimir(diseño);
        signal(turnoLuciano) x3;

  justificacion: |
    Son **dos productor-consumidor encadenados** (usuarios → web → impresores) más un **turno** entre los
    impresores:

    | Semáforo | Tipo | Inicial | Para qué |
    | -------- | ---- | ------- | -------- |
    | `mutexPedidos`, `mutexValidados` | mutex | 1 | cada lista es compartida |
    | `limitePedidos` | contador | 10 | tope de pedidos pendientes (`wait` antes de agregar) |
    | `pedidosPendientes` | contador | 0 | la web espera que haya un pedido |
    | `valPendientes` | contador | 0 | los impresores esperan que haya un diseño validado |
    | `turnoLuciano` | contador | **3** | Luciano puede imprimir 3 antes de ceder |
    | `turnoLeonardo` | contador | 0 | Leonardo espera **3** avisos (`x3`) de Luciano |

    - `signal(limitePedidos)` va apenas la web **retira** el pedido: el lugar ya se liberó, aunque falte
      validar.
    - Los contadores van **antes** que los mutex (si no, se puede retener un mutex esperando que haya algo).
    - El turno se pide **antes** de retirar un validado: si no, un impresor podría llevarse un diseño y
      quedarse esperando el turno con el diseño en la mano.
    - No hace falta mutex para la impresora: el turno ya garantiza que nunca imprimen los dos a la vez.
---

LyL asociados comienza un emprendimiento de impresión 3D. A través de una página web, los usuarios realizan pedidos de impresión cuyos diseños deben ser validados. Para no sobrecargar la página, se tiene un **límite de 10 pedidos pendientes a validar**. Luego de validado, el diseño se envía para su impresión.

Al contar con **una sola impresora** y compartir tareas administrativas, los dueños se turnan imprimiendo primero **Luciano 3 diseños y luego Leonardo 1 diseño**.

Sincronice el siguiente pseudocódigo utilizando semáforos para que cumpla con lo pedido, sin generar deadlocks ni starvation.

Variables compartidas: `pedidos`, `validados`

<div class="codigo-columnas">

**Usuario (N instancias)**

```c
diseño = crearDiseño();
agregar(diseño, pedidos);
```

**WEB (1 instancia)**

```c
while(true) {
  diseño = retirar(pedidos);
  validar(diseño);
  agregar(diseño, validados);
}
```

**Luciano (1 instancia)**

```c
while(true) {
  diseño = retirar(validados);
  imprimir(diseño);
}
```

**Leonardo (1 instancia)**

```c
while(true) {
  diseño = retirar(validados);
  imprimir(diseño);
}
```
