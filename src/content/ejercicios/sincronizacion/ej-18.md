preguntas:
- enunciado: b) ¿Se puede remover por completo algún semáforo sin dejar de cumplir la consigna?
  opciones:
  - texto: 'No: cada uno protege algo distinto y sacar cualquiera rompe el orden o la exclusión'
    explicacion: 'Hay uno que sobra: el orden ya impide que A y C toquen acum a la vez.'
  - texto: 'Sí, generar: B podría generar valores libremente porque A los consume en orden'
    explicacion: Sin generar, B podría pisar valor antes de que A lo lea.
  - texto: 'Sí, mutexAcum: el orden B, A, C ya impide que A y C toquen acum a la vez'
    explicacion: 'Correcta: con la secuencia forzada, nunca hay concurrencia sobre acum.'
  - texto: 'Sí, acumulado: C puede imprimir apenas A suelta el mutex de la variable acum'
    explicacion: Sin acumulado, C podría imprimir antes de que A acumule (se rompe el orden).
  correcta: 2
  justificacion: |
    **Sí, `mutexAcum`.** Los semáforos de secuencia (`generar → valorGenerado → acumulado → generar`)
    dejan a **un solo proceso habilitado por vez**: cuando A modifica `acum`, C está bloqueado en
    `wait(acumulado)`, y cuando C lee `acum`, A está bloqueado en `wait(valorGenerado)`. No hay
    concurrencia sobre `acum`, así que el mutex no protege nada.

    Regla que aparece seguido en las resoluciones: **si el orden está totalmente forzado por semáforos de
    secuencia, no hace falta mutex.**

Considere el siguiente pseudocódigo donde se ejecutan 3 procesos concurrentes sincronizados con semáforos, que comparten las variables `valor` y `acum`. Se desea que ejecuten en orden **"B, A, C, B, A, C…"** sin sufrir condiciones de carrera.

<div class="codigo-columnas">

**Proceso A**

```c
while(true) {
  wait(valorGenerado);
  wait(mutexAcum);
  acum += valor;
  signal(mutexAcum);
  signal(acumulado);
}
```

**Proceso B**

```c
while(true) {
  wait(generar);
  valor = generarValor();
  signal(valorGenerado);
}
```

**Proceso C**

```c
while(true) {
  wait(acumulado);
  wait(mutexAcum);
  printf(Acumulado: %d, acum);
  signal(mutexAcum);
  signal(generar);
}
```

</div>

a) Indique los valores de inicialización de los semáforos para cumplir con la consigna.

b) ¿Podría removerse por completo algún semáforo sin dejar de cumplir la consigna? En caso afirmativo, indique cuál.
