    | `stockMaximo` | contador | 33 | lugares libres en el almacén (la fábrica espera si está lleno) |

    - Un solo `mutexEntrega` para todos sería correcto pero restringiría de más: distribuidores que van a

Una fábrica post-apocalíptica llamada "Vault Tec Ammo" provee de munición a los diferentes asentamientos depositándolas en un almacén cercano. Varios distribuidores retiran las cajas de munición del almacén y las distribuyen a los distintos asentamientos de manera periódica.

Dado que la entrada al almacén es por un túnel estrecho, **como máximo pueden acceder de a 2 a la vez** y el almacén puede guardar **hasta 33 cajas**. Así mismo, los distribuidores **no se cruzan al entregar cajas al líder de un mismo asentamiento** para no iniciar conflictos bélicos.

Las funciones `getID()` y `getDestino(caja)` devuelven [0-9] según el asentamiento que corresponda.

Sincronice el siguiente pseudocódigo que modela el funcionamiento del escenario planteado utilizando únicamente semáforos, sin causar deadlocks ni starvation.

<div class="codigo-columnas">

**Fábrica (1 instancia)**

```c
while(true) {
  caja = fabricarMuniciones();
  depositar(almacén, caja);
}
```

**Distribuidor (5 instancias)**

```c
while(true) {
  caja = retirar(almacén);
  id_asent = getDestino(caja);
  entregar(lider[id_asent], caja);
}
```

**Asentamiento (10 instancias)**

```c
while(true) {
  id_asent = getID();
  caja = recibir(lider[id_asent]);
  cargarArmas();
}
```
