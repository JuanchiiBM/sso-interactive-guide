    nombre: Se imprime la secuencia pedida, en orden, para siempre
  - tipo: sin-deadlock
  solucion: |
    semaphore sem_m = 1, sem_a = 0, sem_l = 0, sem_g = 0, sem_mlg = 1;

    void M() {
      while(1){
        wait(sem_m);
        wait(sem_mlg);
        print("M");
        signal(sem_l);
        signal(sem_a);
      }
    }

    void A() {
      while(1){
        wait(sem_a);
        print("A");
        signal(sem_mlg);
      }
    }

    void L() {
      while(1){
        wait(sem_l);
        wait(sem_mlg);
        print("L");
        signal(sem_g);
        signal(sem_a);
      }
    }

    void G() {
      while(1){
        wait(sem_g);
        wait(sem_mlg);
        print("G");
        signal(sem_m);
        signal(sem_a);
      }
    }
  justificacion: |
    Otra vez la letra repetida (M**A**L**A**G**A**) es la que no sabe quién sigue. Esta solución la resuelve
    con un semáforo **de turno compartido** entre las consonantes (`sem_mlg`): A lo devuelve después de
    imprimir, y cada consonante necesita **su** semáforo **y** el turno.

    - Cada consonante habilita a la siguiente (`M → L → G → M`) **y** a la A.
    - La consonante habilitada no puede imprimir hasta que A devuelva `sem_mlg`: así nunca se pisan.

    Hay otra solución oficial con 4 semáforos que usa `wait(...)x3` en cada consonante. Si la probás, los
    tests la aceptan: las dos respetan la secuencia sin deadlock.
preguntas:
- enunciado: ¿Cuántos semáforos de tipo mutex hacen falta en esta solución?
  opciones:
  - texto: Uno, para proteger la pantalla donde imprimen los cuatro procesos
    explicacion: 'No hace falta: la secuencia ya garantiza que nunca imprimen dos a la vez.'
  - texto: Cuatro, uno por cada proceso que imprime una letra distinta
    explicacion: Los semáforos de cada letra son de sincronización (orden), no de exclusión.
  - texto: 'Ninguno: el orden forzado ya impide que dos impriman a la vez'
    explicacion: 'Correcta: si el orden está totalmente forzado, no queda concurrencia que proteger.'
  - texto: 'Dos: uno para las vocales y otro para las consonantes'
    explicacion: No hay recurso compartido que proteger aparte de la secuencia.
  correcta: 2
  justificacion: |
    Todos los semáforos de la solución son **generales usados para sincronizar** (definen el orden). Un
    mutex protege un recurso compartido de accesos **concurrentes**; acá, como la secuencia está totalmente
    forzada, en ningún momento pueden estar dos procesos imprimiendo a la vez. **Cantidad de mutex: 0**
    (así lo responde la resolución oficial).

    `sem_mlg` puede parecer un mutex (arranca en 1 y se toma y devuelve), pero lo toman **procesos distintos
    de los que lo devuelven**: es un turno, no una exclusión mutua.
