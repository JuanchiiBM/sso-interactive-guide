En un sistema operativo con un planificador de corto plazo **por prioridades fijas con desalojo** (0 es la prioridad más alta), se inicia la ejecución de los siguientes procesos:

<div class="codigo-columnas">

**Proceso A (prioridad 0, llegada 4)**

```c
tarea1()   // 2 ut
wait(S)    // 1 ut
tarea2()   // 1 ut
signal(S)  // 1 ut
```

**Proceso B (prioridad 1, llegada 8)**

```c
while(true){
  monitoreo() // 2 ut
  sleep(2)    // 2 ut
}
```

**Proceso C (prioridad 2, llegada 0)**

```c
tarea3()   // 2 ut
wait(S)    // 1 ut
tarea4()   // 6 ut
signal(S)  // 1 ut
```

</div>

**Nota:** el semáforo S se inicializa en 1, los comentarios indican la duración de cada sentencia, y la duración de `sleep` es de **bloqueo**.

a) Realice el diagrama de Gantt hasta el instante en el que los procesos A y C hayan finalizado.

b) Analice el diagrama de Gantt e indique qué problema referido a la planificación puede observarse. Proponga una técnica para solucionarlo, indicando cómo impactaría en el ítem anterior.
