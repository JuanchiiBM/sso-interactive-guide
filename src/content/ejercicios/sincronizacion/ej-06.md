titulo: Secuencia A-B-A-B
tema: parcial-1/sincronizacion

tipo: codigo
dificultad: facil
tags: [semaforos, orden, alternancia]
semaforos:
- procesos:
  - nombre: A
    instancias: 1
    codigo: |
      while(TRUE){
        print("A");
      }
  - nombre: B
    instancias: 1
    codigo: |
      while(TRUE){
        print("B");
      }
  acciones:
    print("A"): {}
    print("B"): {}
  tests:
  - tipo: secuencia
    acciones:
    - print("A")
    - print("B")
  - tipo: sin-deadlock
  - tipo: todas-ejecutan
  solucion: |
    semaphore turno_a = 1, turno_b = 0;

    void A() {
      while(TRUE){
        wait(turno_a);
        print("A");
        signal(turno_b);
      }
    }

    void B() {
      while(TRUE){
        wait(turno_b);
        print("B");
        signal(turno_a);
      }
    }
  justificacion: |
    Cada proceso espera **su turno** y al terminar le pasa el turno al otro. Dos semáforos de
    sincronización:

    - `turno_a = 1`: A arranca primero (la secuencia empieza en A).
    - `turno_b = 0`: B espera hasta que A imprima.

    Invertir los valores iniciales haría la secuencia B-A-B-A; dejar ambos en 0 es deadlock.
---

Dados dos procesos (A y B) donde cada uno realiza una tarea, sincronícelos para cumplir con la secuencia de ejecución: **A-B-A-B-A-...**

<div class="codigo-columnas">

**Proceso A**

```c
while(TRUE){
  print("A");
}
```

**Proceso B**

```c
while(TRUE){
  print("B");
}
```
