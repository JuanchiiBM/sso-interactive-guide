Se dispone del siguiente pseudocódigo, utilizado para dos procesos que se envían mensajes a través de una lista, cuyo **máximo de elementos es 10**. Existe una variable global llamada `LISTA`.

<div class="codigo-columnas">

**Proceso 1 (N instancias)**

```c
wait(C);
wait(B);
enviar_mensaje(LISTA);
signal(B);
signal(A);
```

**Proceso 2 (N instancias)**

```c
wait(A);
wait(B);
recibir_mensaje(LISTA);
signal(B);
signal(C);
```

</div>
