titulo: Mutua exclusión sobre un contador
tema: parcial-1/sincronizacion
fuente: { guia: Guía de Ejercicios – Sincronización (v.2C2026), numero: 1 }
tipo: codigo
dificultad: facil
tags: [semaforos, mutex]
semaforos:
- procesos:
  - nombre: Hilo
    instancias: 3
    codigo: |
      while(TRUE){
        contador++;
      }
  acciones:
    contador++:
      recursos:
      - contador
  tests:
  - tipo: exclusion
    recurso: contador
  - tipo: sin-deadlock
  - tipo: todas-ejecutan
  solucion: |
    semaphore mutex = 1;

    void Hilo() {
      while(TRUE){
        wait(mutex);
        contador++;
        signal(mutex);
      }
    }
  justificacion: |
    `contador++` **no es atómico**: se traduce en leer, sumar y escribir. Si dos hilos se intercalan
    entre esas instrucciones, se pierde un incremento (condición de carrera).

    Se usa un **mutex** (semáforo binario inicializado en **1**): el primer hilo que hace `wait` lo baja a
    0 y entra; los demás se bloquean hasta el `signal`. Así la región crítica (`contador++`) la ejecuta
    un solo hilo a la vez.

    - Tipo: **mutex** (binario), valor inicial 1.
    - Si se inicializa en 0, nadie entra nunca: **deadlock**.
    - La cantidad de `wait` y `signal` del mutex tiene que ser la misma.
---

Dado un sistema con N hilos que modifican una variable global compartida, sincronice el siguiente código para evitar inconsistencias y garantizar la mutua exclusión. ¿Qué tipo de semáforo utilizaría? Justificar.

**Hilo (N instancias)**

```c
while(TRUE){
  contador++;
}
```
