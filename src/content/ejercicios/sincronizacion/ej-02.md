Dados los siguientes procesos con variables compartidas, sincronícelos para garantizar la mutua exclusión sobre ellas, además identifique las regiones críticas.
_Indique cada tipo de semáforo empleado para su solución._

**variables compartidas: a=b=1**

<div class="codigo-columnas">

**Proceso A**

```c
variable_local d = 1;
while(TRUE){
  a = a + d;
  d = d * d;
  b = b - d;
}
```

**Proceso B**

```c
variable_local e = 2;
while(TRUE){
  b = b * e;
  e = e ^ e;
  a++;
}
```
