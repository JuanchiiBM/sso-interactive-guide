Un conjunto de científicos decide modelar la melodía de una canción de una popular banda de rock argentino. Para ello, desarrollan un proceso con cuatro hilos, donde cada uno toca una nota de la melodía (a veces repetidas veces) simulando el sonido de un saxo.

La melodía es: **RE#, RE#, RE#, RE#, DO#, DO#, SOL, SOL#**.

<div class="codigo-columnas">

**Saxo Tenor**

```c
while(true){
  tocar(DO#);
  tocar(DO#);
}
```

**Saxo Alto**

```c
while(true){
  tocar(RE#);
}
```

**Saxo Soprano**

```c
while(true){
  tocar(SOL);
}
```

**Saxo Sopranino**

```c
while(true){
  tocar(SOL#);
}
```

</div>

Sincronice los hilos usando exclusivamente semáforos, para lograr que la melodía deseada se reproduzca infinitamente, sin que se produzca deadlock ni starvation.
