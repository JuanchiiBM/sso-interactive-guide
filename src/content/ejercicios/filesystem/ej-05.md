preguntas:
  - enunciado: 'a) ¿Qué ocurre si un proceso P2 intenta abrirlo para escritura?'
    opciones:
      - texto: 'Puede escribir si no pide el lock, porque el SO no lo controla'
        explicacion: 'Eso pasa con uno sugerido; el obligatorio lo controla el SO.'
      - texto: 'El SO se lo impide: la syscall falla o P2 se bloquea hasta que P1 libere'
        explicacion: 'Correcta: un exclusivo no admite a nadie más.'
      - texto: 'Puede escribir: el exclusivo frena solo a otros lectores mientras P1 esté leyendo'
        explicacion: 'El exclusivo frena a cualquier otro proceso, lea o escriba.'
    correcta: 1
    justificacion: |
      - **Exclusivo:** mientras P1 tenga el lock, nadie más accede.
      - **Obligatorio:** lo hace cumplir el SO, pida P2 el lock o no.

      La syscall de P2 **no se realiza**: devuelve un error, o bloquea a P2 hasta que P1 libere el
      lock, según la syscall sea no bloqueante o bloqueante (resolución del 2C2024 TT). El SO lo sabe
      por la **tabla global de archivos abiertos**, donde está registrado el lock.
  - enunciado: 'b) ¿Qué ocurre si un proceso P2 intenta abrirlo para lectura?'
    opciones:
      - texto: 'Lee junto con P1, porque los dos solo leen y leer no modifica el archivo'
        explicacion: 'Eso pasaría con uno compartido.'
      - texto: 'Lee, siempre que no pida el lock'
        explicacion: 'Con un lock obligatorio, no pedirlo no sirve para saltearlo.'
      - texto: 'El SO se lo impide igual que en a): no se comparte ni entre lectores'
        explicacion: 'Correcta: falla o espera a que P1 libere.'
    correcta: 2
    justificacion: |
      El lock **exclusivo** no distingue modos: aunque P1 y P2 solo quieran leer, no pueden tenerlo a
      la vez. Y como es **obligatorio**, el SO frena la apertura de P2 (error o bloqueo) sin importar
      si P2 pidió el lock.
  - enunciado: 'c) ¿Hubieran cambiado sus respuestas si P1 lo hubiese abierto en modo escritura?'
    opciones:
      - texto: 'No: el exclusivo ya frenaba a todos'
        explicacion: 'Correcta: a) y b) quedan igual.'
      - texto: 'Sí: ahora P2 podría leer, porque solo P1 escribe'
        explicacion: 'Un lector junto a un escritor es justo lo que el lock tiene que impedir.'
      - texto: 'Sí: el SO dejaría de controlar el lock mientras P1 escribe'
        explicacion: 'El modo de P1 no cambia quién impone el lock.'
    correcta: 0
    justificacion: |
      Con un lock **obligatorio exclusivo**, P2 ya quedaba afuera para leer y para escribir. Que P1
      escriba no puede restringir más: las respuestas son las mismas.
