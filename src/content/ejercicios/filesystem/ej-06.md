preguntas:
  - enunciado: 'a) ¿Qué ocurre si un proceso P2 intenta abrirlo para escritura?'
    opciones:
      - texto: 'Escribe mientras P1 lee, porque el lock es compartido'
        explicacion: 'El compartido se comparte solo entre lectores.'
      - texto: 'Escribe si no pide el lock, porque el SO solo controla a los que lo piden'
        explicacion: 'Eso pasa con uno sugerido; el obligatorio lo controla el SO.'
      - texto: 'El SO se lo impide: falla o espera a que P1 libere'
        explicacion: 'Correcta: escribir requiere el archivo para uno solo.'
    correcta: 2
    justificacion: |
      Un lock **compartido** admite varios **lectores**, pero quien escribe necesita el archivo para
      él solo. Como es **obligatorio**, el SO hace cumplir esa regla: la syscall de P2 devuelve un
      error o lo bloquea hasta que P1 (y cualquier otro lector) libere el lock.
  - enunciado: 'b) ¿Qué ocurre si un proceso P2 intenta abrirlo para lectura?'
    opciones:
      - texto: 'Puede leer: el SO le da el lock compartido junto con P1'
        explicacion: 'Correcta: dos lectores son compatibles.'
      - texto: 'El SO se lo impide hasta que P1 libere el lock, aunque P2 también quiera solo leer'
        explicacion: 'Eso pasaría con uno exclusivo.'
      - texto: 'Puede leer solo si no pide el lock, porque pedirlo lo haría esperar a P1'
        explicacion: 'Pedir un lock compartido para leer no espera a otro lector.'
    correcta: 0
    justificacion: |
      Es el caso para el que existe el lock **compartido**: P1 y P2 leen a la vez. En el ejercicio de
      parcial 1C2025 TT (obligatorio y compartido), dos procesos toman el lock para leer y los dos
      imprimen sin esperarse.

      Ojo: en ese mismo ejercicio, un proceso que hace `read` **sin** tomar el lock recibe un error.
      Acá P2 abre el archivo para lectura y, con un lock obligatorio, el SO le aplica el lock al
      abrir: lee compartiéndolo con P1.
  - enunciado: 'c) ¿Hubieran cambiado sus respuestas si P1 lo hubiese abierto en modo escritura?'
    opciones:
      - texto: 'No: el compartido sigue admitiendo lectores'
        explicacion: 'Admite lectores solo mientras nadie escribe.'
      - texto: 'Sí, cambia b): con P1 escribiendo, P2 tampoco puede leer'
        explicacion: 'Correcta: a) queda igual.'
      - texto: 'Sí, cambia a): P2 podría escribir junto con P1 y el SO ordenaría las escrituras'
        explicacion: 'Dos escritores nunca comparten el lock.'
    correcta: 1
    justificacion: |
      | P2 quiere… | P1 lee | P1 escribe |
      | --- | --- | --- |
      | escribir | el SO lo frena | el SO lo frena |
      | leer | **puede** | **el SO lo frena** |

      Cambia b): con P1 escribiendo, el lock no se comparte con nadie y el SO frena también la
      lectura de P2 (error o bloqueo). a) no cambia.

**lectura**. Sabiendo que el lock utilizado es de tipo **obligatorio compartido**, responda:

- a) ¿Qué ocurre si un proceso P2 intenta abrirlo para escritura?
- b) ¿Qué ocurre si un proceso P2 intenta abrirlo para lectura?
- c) ¿Hubieran cambiado sus respuestas si P1 lo hubiese abierto en modo **escritura**?
