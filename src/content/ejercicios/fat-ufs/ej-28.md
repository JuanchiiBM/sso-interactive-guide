nota: |
  En a) los archivos regulares pueden estar **vacíos** (tamaño 0, sin clusters asignados). Como hace
  siempre la cátedra, se ignoran los valores reservados de la FAT (libre, fin, dañado): los 2^16
  valores de un puntero de 16 bits cuentan como clusters.
calculos:
  - enunciado: 'a) Máximo de archivos regulares en el sistema.'
    campos:
      - { etiqueta: 'Archivos', respuesta: 524288, unidad: archivos }
    justificacion: |
      Cada entrada de directorio mide `18 + 4 + 8 + 2 = 32 B`. El único directorio (el raíz) tiene
      tamaño fijo, así que el límite es cuántas entradas entran:

      `16 MiB / 32 B = 2^24 / 2^5 = 2^19 =` **524.288 archivos**.

      Si cada archivo tuviera que ocupar al menos un cluster, también limitaría la cantidad de clusters
      libres.
  - enunciado: 'b) Tamaño máximo real de un archivo nuevo.'
    campos:
      - { etiqueta: 'Archivo nuevo máximo', respuesta: 16, unidad: MiB }
    justificacion: |
      El puntero al primer cluster mide **2 B = 16 bits** → el FS direcciona `2^16` clusters:

      `2^16 × 512 B = 2^16 × 2^9 = 2^25 B = 32 MiB` (menos que el disco de 64 MiB).

      De esos 32 MiB, el directorio raíz (que también es un archivo) ya ocupa 16 MiB: a un archivo
      nuevo le quedan como máximo **16 MiB**.
  - enunciado: 'c) Tamaño de la tabla FAT.'
    campos:
      - { etiqueta: 'Tabla FAT', respuesta: 128, unidad: KiB }
    justificacion: |
      Una entrada por cluster direccionable, de 2 B cada una:

      `2^16 × 2 B = 2^17 B =` **128 KiB**.

Un filesystem de tipo FAT está limitado a un único directorio (el raíz), el cual tiene un tamaño fijo
de 16 MiB y sus entradas de directorio contienen los siguientes atributos fijos: nombre (18 bytes),
tamaño (4 bytes), fechas de creación (8 bytes) y el puntero al primer cluster de datos (2 bytes).
Este FS está formateado sobre un disco de 64 MiB y clusters de 512 bytes. Responda las siguientes
preguntas tomando siempre el estado original del sistema:

- a) ¿Cuál es el máximo de archivos regulares que podría haber en este sistema? (descartando el
  espacio ocupado por la FAT u otras estructuras administrativas)
- b) ¿Cuál es el tamaño máximo real que podría tener un archivo nuevo? (descartando el espacio
  ocupado por la FAT u otras estructuras administrativas)
- c) ¿Qué tamaño ocupa la tabla FAT en este sistema?
