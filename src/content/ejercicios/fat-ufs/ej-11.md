  - enunciado: 'a) El primer bloque de datos del archivo.'
    campos:
      - { etiqueta: 'Bloques de punteros', respuesta: 0 }
      - { etiqueta: 'Bloques de datos', respuesta: 1 }
    justificacion: |
      **Criterio de la cátedra:** se cuentan los bloques de punteros y de datos que se leen; el
      **inodo no**, porque el archivo está abierto y su inodo ya está en memoria. Los bloques lógicos
      se numeran desde 0.

      Rango de bloques lógicos de cada puntero (256 punteros por bloque, ver Ej. 10):

      | Puntero | Bloques lógicos |
      | --- | --- |
      | 4 directos | 0 a 3 |
      | Indirecto simple | 4 a 259 (256) |
      | Indirecto doble | 260 a 65.795 (65.536) |

      El primer bloque es el **0**: lo apunta el primer directo. Se lee solo el bloque de datos:
      **0 de punteros + 1 de datos**.
  - enunciado: 'b) El bloque lógico número 4, numerando desde cero.'
    campos:
      - { etiqueta: 'Bloques de punteros', respuesta: 1 }
      - { etiqueta: 'Bloques de datos', respuesta: 1 }
    justificacion: |
      Los directos cubren 0 a 3: el bloque 4 es el **primero del indirecto simple** (entrada 0 del
      bloque de punteros).

      Se lee el bloque de punteros del IS y después el de datos: **1 de punteros + 1 de datos**.
  - enunciado: 'c) El bloque lógico número 260.'
    campos:
      - { etiqueta: 'Bloques de punteros', respuesta: 2 }
      - { etiqueta: 'Bloques de datos', respuesta: 1 }
    justificacion: |
      El simple termina en el 259 (`4 + 256 − 1`): el 260 es el **primero del indirecto doble**.

      Dentro del doble es el bloque `260 − 260 = 0`: entrada `0 div 256 = 0` del bloque de nivel 1 y
      entrada `0 mod 256 = 0` del bloque de nivel 2.

      Se leen el bloque de punteros del ID, el bloque de punteros simple que cuelga de él y el de
      datos: **2 de punteros + 1 de datos**.


Para cada caso, indique cuántos bloques de punteros y cuántos bloques de datos deben leerse.
Utilizando exactamente la misma configuración del ejercicio anterior (bloques de 1 KiB, punteros de
4 bytes, 4 punteros directos, 1 indirecto simple y 1 indirecto doble), se desea leer:

- a) El primer bloque de datos del archivo.
- b) El bloque lógico número 4, numerando desde cero.
- c) El bloque lógico número 260.
