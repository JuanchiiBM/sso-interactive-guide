  En b) se cuenta **un acceso a la tabla de páginas por página** (no por byte) y la FAT está

calculos:
  - enunciado: 'a) ¿Cuántos clusters son necesarios para persistir el archivo?'
    campos:
      - { etiqueta: 'Tamaño de cluster', respuesta: 16, unidad: KiB }
      - { etiqueta: 'Clusters', respuesta: 64, unidad: clusters }
    justificacion: |
      FAT32 tiene entradas de 4 B: `64 MiB / 4 B = 2^26 / 2^2 = 2^24` entradas, una por cluster.

      Tamaño de cluster: `256 GiB / 2^24 = 2^38 / 2^24 = 2^14 B =` **16 KiB**.

      Clusters del archivo: `1 MiB / 16 KiB = 2^20 / 2^14 =` **64 clusters**.
preguntas:
  - enunciado: 'b) ¿Cuántos accesos a memoria y a disco hacen falta para completar la operación?'
    opciones:
      - texto: '256 a memoria (128 a la tabla de páginas + 128 a frames) y 64 a disco'
        explicacion: 'Faltan los 64 accesos a la FAT (en memoria) y la entrada de directorio en disco.'
      - texto: '320 a memoria (128 a TP + 128 a frames + 64 a la FAT) y 65 a disco (1 entrada de directorio + 64 clusters)'
        explicacion: Correcta (criterio de la cátedra).
      - texto: '192 a memoria (128 a frames + 64 a la FAT) y 129 a disco (64 clusters + 64 entradas de la FAT + 1 de directorio)'
        explicacion: 'Con paginación cada lectura de un frame pasa antes por la tabla de páginas; y la FAT se actualiza en memoria.'
      - texto: '320 a memoria y 128 a disco: un acceso por cada página de 8 KiB'
        explicacion: 'El disco se escribe por clusters (16 KiB): son 64, no 128.'
    correcta: 1
    justificacion: |
      **Memoria.** El archivo ocupa `1 MiB / 8 KiB = 128 páginas`:

      - 128 accesos a la **tabla de páginas** (traducir cada página a su frame),
      - 128 accesos a los **frames** para leer los datos,
      - 64 accesos a la **tabla FAT** (una entrada por cluster asignado; la FAT está en memoria).

      Total: **320 accesos a memoria**.

      **Disco.** 1 acceso para escribir la **entrada de directorio** del archivo nuevo + 64 para
      escribir los **clusters**: **65 accesos a disco**.

      El conteo depende del criterio (ver la nota): si se cuenta leer el directorio o grabar la FAT
      en disco, los números suben.
  - enunciado: 'c) Los clusters 124, 332 y 446 están corruptos. ¿Se perdió el archivo completo? ¿Se puede recuperar la información?'
    opciones:
      - texto: 'Sí, se perdió entero: si un cluster de la cadena falla, FAT descarta todo el archivo'
        explicacion: 'Los demás clusters siguen intactos en el disco.'
      - texto: 'No se perdió nada: la FAT guarda una copia de los datos de cada cluster'
        explicacion: 'La FAT guarda números de cluster, no datos.'
      - texto: 'Solo se pierden esos 3 clusters; para seguir la cadena después de cada uno hay que usar la copia de respaldo de la FAT o una herramienta de recuperación'
        explicacion: Correcta.
      - texto: 'Solo se pierden esos 3 clusters, y la cadena sigue sola porque la entrada de un cluster dañado conserva el siguiente'
        explicacion: 'La entrada del cluster dañado queda marcada como ERROR: se pierde el "siguiente".'
    correcta: 2
    justificacion: |
      **No se perdió el archivo completo**, solo el contenido de los clusters 124, 332 y 446, que no
      se pueden leer. El resto de los clusters sigue en el disco.

      El problema es la **cadena**: la FAT marca esas entradas con el código de **ERROR** (dañado), y
      con eso se pierde el dato de cuál era el cluster **siguiente**:

      ```
      122 → 78
      123 → LIBRE
      124 → ERROR   ← ¿cuál seguía?
      125 → 39
      ```

      Para recuperar lo que viene después de cada cluster dañado hay que usar la **copia de respaldo
      de la FAT** (FAT32 mantiene una segunda copia) o una herramienta que reconstruya la cadena.

En un sistema que implementa paginación pura sin memoria virtual, con una memoria particionada en
frames de 8 KiB, un docente aleatorio terminó de escribir el examen recuperatorio de cierta materia
(el cual ocupó 1 MiB) y desea guardarlo en un file system FAT32 (creando un nuevo archivo). Sabiendo
que el tamaño del volumen es de 256 GiB y que su tabla FAT ocupa 64 MiB, responda las siguientes
preguntas:

- a) ¿Cuántos clusters son necesarios para persistir el archivo?
- b) ¿Cuántos accesos a memoria y a disco fueron necesarios para completar la operación? Justifique
  cada acceso incluyendo a qué estructuras se accedieron.
- c) Cuando este docente presionó "Guardar" y se disponía a descansar luego de cerrar el editor de
  texto, siente un escalofrío que lo empuja a abrir el archivo recién creado para verificar que todo
  esté bien. Pero lamentablemente se encuentra con este mensaje: "El archivo no se guardó
  correctamente. Los clusters 124, 332 y 446 están corruptos".
  Sabiendo esto, responda: ¿Se perdió el archivo completo? ¿Por qué? ¿Se pueden recuperar los
  clusters dañados? Justifique explicando qué acciones se podrían llevar a cabo para recuperar la
  información y detalle los pasos a seguir.
