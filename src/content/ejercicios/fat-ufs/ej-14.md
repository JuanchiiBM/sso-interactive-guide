calculos:
  - enunciado: 'Tamaño máximo teórico de un archivo para cada conformación de punteros.'
    campos:
      - { etiqueta: 'a) 12 directos', respuesta: 12, unidad: KiB }
      - { etiqueta: 'b) 12 directos + 1 indirecto', respuesta: 268, unidad: KiB }
      - {
          etiqueta: 'c) 12 directos + 1 indirecto + 1 doble + 1 triple',
          respuesta: 16843020,
          unidad: KiB,
        }
    justificacion: |
      **Punteros por bloque:** `1 KiB / 4 bytes = 2^10 / 2^2 = 256`.

      Cada puntero del inodo cubre una cantidad de bloques de datos de 1 KiB:

      | Puntero | Bloques de datos | Tamaño |
      | --- | --- | --- |
      | Directo | 1 | 1 KiB |
      | Indirecto simple | 256 | 256 KiB |
      | Indirecto doble | 256<sup>2</sup> = 65.536 | 64 MiB |
      | Indirecto triple | 256<sup>3</sup> = 16.777.216 | 16 GiB |

      - a) `12 × 1 KiB = 12 KiB`.
      - b) `(12 + 256) × 1 KiB = 268 KiB`.
      - c) `(12 + 256 + 65.536 + 16.777.216) × 1 KiB = 16.843.020 KiB`, unos **16,06 GiB**.

      El triple domina: los directos y el simple casi no cambian el máximo, pero hacen que los
      archivos chicos se lean sin pasar por bloques de punteros.
---

Se tiene un sistema con ext2 como filesystem. Los bloques de disco son de 1 KiB y los punteros son de
4 bytes. Indique el tamaño máximo teórico de un archivo para las siguientes conformaciones de
punteros:

- a) Solamente 12 punteros directos
- b) 12 punteros directos y 1 indirecto
- c) 12 directos, 1 indirecto, 1 doblemente indirecto y 1 triplemente indirecto
