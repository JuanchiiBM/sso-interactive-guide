      - a) Cada puntero directo apunta a **un** bloque de datos: 4 directos → **4 bloques**.

      - c) El indirecto simple apunta a un bloque de 256 punteros, cada uno a un bloque de datos:

      - d) El indirecto doble apunta a un bloque de 256 punteros, cada uno a otro bloque de 256
        punteros: `256 × 256 = 256^2 = 65.536` bloques.

Un filesystem EXT2 utiliza bloques de 1 KiB y punteros de 4 bytes. Un inodo posee 4 punteros
directos, 1 indirecto simple y 1 indirecto doble.

| Inodo         |
| ------------- |
| … atributos … |
| 1 PD          |
| 2 PD          |
| 3 PD          |
| 4 PD          |
| 5 IS          |
| 6 ID          |

Se pide:

- a) ¿Cuántos bloques de datos pueden direccionarse mediante los punteros directos?
- b) ¿Cuántos punteros entran en un bloque de indirección?
- c) ¿Cuántos bloques de datos pueden direccionarse mediante el indirecto simple?
- d) ¿Cuántos mediante el indirecto doble?
- e) ¿Cuál es el tamaño máximo teórico de archivo direccionable con esta configuración?
