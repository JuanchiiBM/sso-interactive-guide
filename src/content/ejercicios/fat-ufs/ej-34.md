Un sistema utiliza segmentación pura (sin memoria virtual) con una memoria de 64 KiB. El mismo
cuenta además con un FS tipo FAT16 cuyos bloques son de 256 B. En un momento existen solo dos
procesos con las siguientes tablas de segmentos:

<div class="codigo-columnas">

**Proceso 1**

| Base | Tamaño |
| --- | --- |
| 0 | 8192 |
| 34816 | 8192 |
| 12288 | 14336 |
| – | – |

**Proceso 2**

| Base | Tamaño |
| --- | --- |
| 59392 | 6144 |
| 28672 | 6144 |
| 49152 | 6144 |
| – | – |

</div>

- a) Indique qué direcciones lógicas (segmento y desplazamiento) generarían a las direcciones físicas
  12538, 53152 y 65535.
- b) Si el proceso 1 leyera un archivo desde el byte 2048 al 4095 y se asignara ese contenido en un
  nuevo segmento, indique:
  - i) ¿Cómo quedaría la tabla de segmentos del proceso 1 si se utiliza asignación **Best Fit**?
  - ii) ¿Cuántos bloques en disco tuvieron que ser leídos? ¿Y cuántas entradas de la FAT?
