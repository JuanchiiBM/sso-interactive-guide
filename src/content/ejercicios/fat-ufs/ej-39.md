  "Espacio disponible" = lo que queda libre en los bloques de la partición después de ubicar los

  directorios.
calculos:
  - enunciado: 'a) Espacio disponible antes y después de la migración.'
    campos:
      - { etiqueta: 'Libre antes (FAT12)', respuesta: 0, unidad: MiB }
      - { etiqueta: 'Bloque de FAT16', respuesta: 2, unidad: KiB }
      - { etiqueta: 'Libre después (FAT16)', respuesta: 22, unidad: MiB }
    justificacion: |
      **Antes**, con bloques de 32 KiB, cada archivo de 10 KiB ocupa un bloque entero (22 KiB de
      **fragmentación interna**):

      `32 MiB + 64 MiB + 1024 × 32 KiB = 32 + 64 + 32 = 128 MiB` → la partición está llena:
      **0 MiB** libres.

      **Después**, el menor bloque con el que FAT16 sigue direccionando los 128 MiB:

      `128 MiB / 2^16 = 2^27 / 2^16 = 2^11 B =` **2 KiB**.

      Cada archivo de 10 KiB ocupa exactamente 5 bloques (sin fragmentación interna):

      `32 + 64 + 1024 × 10 KiB = 96 MiB + 10 MiB = 106 MiB` → libres `128 − 106 =` **22 MiB**.
  - enunciado: 'b) Tamaño de la tabla FAT antes y después de la migración.'
    campos:
      - { etiqueta: 'FAT12', respuesta: 6, unidad: KiB }
      - { etiqueta: 'FAT16', respuesta: 128, unidad: KiB }
    justificacion: |
      **Antes:** `128 MiB / 32 KiB = 2^12` bloques: usa todas las entradas de FAT12, de 12 bits
      (1,5 B):

      `2^12 × 1,5 B = 6144 B =` **6 KiB**.

      **Después:** `2^16` entradas de 16 bits (2 B):

      `2^16 × 2 B = 2^17 B =` **128 KiB**.

      La FAT crece 21 veces, pero se recuperan 22 MiB de fragmentación interna.
---

Un FS tipo FAT12 con bloques de 32 KiB está formateado sobre una partición de 128 MiB. Dentro del
mismo se hallan 2 archivos cuyos tamaños son 32 MiB y 64 MiB, así mismo, se hallan otros 1024
archivos de 10 KiB cada uno.

Para optimizar el uso del espacio en disco, se decide migrar dicho FS a un FAT16 con el mínimo tamaño
de bloque posible para seguir direccionando toda la partición. Responda:

a) ¿Cuánto **espacio disponible** tenía el FS antes de la migración y después de la misma?

b) ¿Cuánto **espacio ocupa la tabla FAT** antes de la migración y después de la misma?
