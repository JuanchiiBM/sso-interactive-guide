calculos:
  - enunciado: 'a) ¿Cuál sería el tamaño mínimo de cluster para poder direccionar el disco?'
    campos:
      - { etiqueta: 'Cluster mínimo', respuesta: 64, unidad: KiB }
    justificacion: |
      FAT16 numera 2<sup>16</sup> clusters. Para cubrir los 4 GiB:

      `4 GiB / 2^16 = 2^32 / 2^16 = 2^16 bytes = 64 KiB`

      Con un cluster más chico (32 KiB) se llegaría solo a 2 GiB y la mitad del disco quedaría sin
      direccionar.
  - enunciado: 'b) ¿Qué espacio en disco ocuparía cada archivo?'
    campos:
      - { etiqueta: 'Archivo de 1 KiB', respuesta: 64, unidad: KiB }
      - { etiqueta: 'Archivo de 20 KiB', respuesta: 64, unidad: KiB }
      - { etiqueta: 'Archivo de 1 MiB', respuesta: 1024, unidad: KiB }
    justificacion: |
      Un archivo ocupa siempre **clusters enteros**: se redondea hacia arriba.

      | Archivo | Clusters | Ocupa | Desperdicio |
      | --- | --- | --- | --- |
      | 1 KiB | ⌈1 / 64⌉ = 1 | 64 KiB | 63 KiB |
      | 20 KiB | ⌈20 / 64⌉ = 1 | 64 KiB | 44 KiB |
      | 1 MiB | 1024 / 64 = 16 | 1 MiB (1024 KiB) | 0 |

      Los tres archivos suman 1045 KiB de datos y ocupan 1152 KiB.
preguntas:
  - enunciado: 'c) ¿Qué principal desventaja presenta este esquema de formateo?'
    opciones:
      - texto: 'La tabla FAT ocupa demasiado lugar en el disco'
        explicacion: 'Son 2<sup>16</sup> entradas de 2 bytes: 128 KiB, una parte ínfima de 4 GiB.'
      - texto: 'Mucha fragmentación interna'
        explicacion: 'Correcta: con clusters de 64 KiB, cada archivo chico desperdicia casi todo su cluster.'
      - texto: 'Mucha fragmentación externa'
        explicacion: 'La asignación encadenada usa cualquier cluster libre: no necesita huecos contiguos.'
      - texto: 'No se puede direccionar todo el disco'
        explicacion: 'Con 64 KiB se direcciona exactamente todo: 2<sup>16</sup> × 64 KiB = 4 GiB.'
    correcta: 1
    justificacion: |
      Para cubrir un disco grande con pocos bits por entrada, FAT16 obliga a usar **clusters
      grandes**, y eso dispara la **fragmentación interna**: el inciso b) lo muestra, un archivo de
      1 KiB ocupa 64 KiB (63 KiB perdidos).

      Con muchos archivos chicos, buena parte del disco queda ocupada sin datos. La salida es un
      formato con más bits por entrada (FAT32), que permite clusters chicos en el mismo disco.
