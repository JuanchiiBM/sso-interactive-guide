calculos:
  - enunciado: 'a) ¿Cuántos bloques necesita cada archivo?'
    campos:
      - { etiqueta: 'Archivo de 1 KiB', respuesta: 1, unidad: bloques }
      - { etiqueta: 'Archivo de 3 KiB', respuesta: 2, unidad: bloques }
      - { etiqueta: 'Archivo de 5 KiB', respuesta: 3, unidad: bloques }
    justificacion: |
      Un archivo ocupa **bloques enteros**: se divide por el tamaño de bloque y se redondea hacia
      arriba.

      - 1 KiB: `⌈1 / 2⌉ = 1` bloque.
      - 3 KiB: `⌈3 / 2⌉ = 2` bloques.
      - 5 KiB: `⌈5 / 2⌉ = 3` bloques.
  - enunciado: 'b) ¿Cuánto espacio físico ocupa cada uno?'
    campos:
      - { etiqueta: 'Archivo de 1 KiB', respuesta: 2, unidad: KiB }
      - { etiqueta: 'Archivo de 3 KiB', respuesta: 4, unidad: KiB }
      - { etiqueta: 'Archivo de 5 KiB', respuesta: 6, unidad: KiB }
    justificacion: |
      Espacio físico = bloques × 2 KiB: `1 × 2 = 2 KiB`, `2 × 2 = 4 KiB` y `3 × 2 = 6 KiB`.

      Los tres archivos suman 9 KiB de datos y ocupan 12 KiB en disco.
  - enunciado: 'c) ¿Cuánta fragmentación interna produce cada archivo?'
    campos:
      - { etiqueta: 'Archivo de 1 KiB', respuesta: 1, unidad: KiB }
      - { etiqueta: 'Archivo de 3 KiB', respuesta: 1, unidad: KiB }
      - { etiqueta: 'Archivo de 5 KiB', respuesta: 1, unidad: KiB }
    justificacion: |
      La **fragmentación interna** es lo que sobra en el último bloque: espacio ocupado − tamaño
      del archivo.

      | Archivo | Ocupa | Fragmentación interna |
      | --- | --- | --- |
      | 1 KiB | 2 KiB | 1 KiB |
      | 3 KiB | 4 KiB | 1 KiB |
      | 5 KiB | 6 KiB | 1 KiB |

      Los tres son múltiplos impares de 1 KiB, así que a los tres les sobra medio bloque.
  - enunciado: 'd) Con bloques de 4 KiB, ¿cuánta fragmentación interna produce cada archivo?'
    campos:
      - { etiqueta: 'Archivo de 1 KiB', respuesta: 3, unidad: KiB }
      - { etiqueta: 'Archivo de 3 KiB', respuesta: 1, unidad: KiB }
      - { etiqueta: 'Archivo de 5 KiB', respuesta: 3, unidad: KiB }
    justificacion: |
      Se repite la cuenta con bloques de 4 KiB:

      | Archivo | Bloques | Ocupa | Fragmentación interna |
      | --- | --- | --- | --- |
      | 1 KiB | 1 | 4 KiB | 3 KiB |
      | 3 KiB | 1 | 4 KiB | 1 KiB |
      | 5 KiB | 2 | 8 KiB | 3 KiB |

      Se usan **menos bloques** (4 en vez de 6: menos entradas que administrar y recorrer), pero la
      fragmentación interna total pasa de **3 KiB a 7 KiB**: los tres archivos ocupan 16 KiB para
      9 KiB de datos. Con bloques más grandes, en el peor caso se pierde casi un bloque entero por
      archivo.

Un filesystem del tipo FAT utiliza bloques de 2 KiB. Se almacenan tres archivos de 1 KiB, 3 KiB y
5 KiB. Se pide:

- a) Calcular cuántos bloques necesita cada archivo.
- b) Determinar cuánto espacio físico ocupa cada uno.
- c) Calcular la fragmentación interna producida por cada archivo.
- d) ¿Qué cambiaría si el tamaño de bloque fuera de 4 KiB?
