    campos:
      - { etiqueta: 'Teórico: x de 2<sup>x</sup> bytes', respuesta: 76 }
      - { etiqueta: 'Real', respuesta: 10, unidad: TiB }
    justificacion: |
      Un puntero de 8 bytes (64 bits) numera 2<sup>64</sup> bloques:

      - Teórico: `2^64 × 4 KiB = 2^64 × 2^12 = 2^76 bytes` (64 ZiB).
      - Real: limitado por el disco → **10 TiB**.
  - enunciado: 'b) Tamaño máximo teórico de un archivo.'
    campos:
      - { etiqueta: 'Archivo máximo teórico', respuesta: 1075839016, unidad: KiB }
    justificacion: |
      Punteros por bloque: `4 KiB / 8 bytes = 512`.

      | Punteros | Bloques de datos |
      | --- | --- |
      | 10 directos | 10 |
      | 2 indirectos dobles | 2 × 512<sup>2</sup> = 524.288 |
      | 2 indirectos triples | 2 × 512<sup>3</sup> = 268.435.456 |
      | **Total** | **268.959.754** |

      `268.959.754 × 4 KiB = 1.075.839.016 KiB` = 1 TiB + 2 GiB + 40 KiB.

      Entra holgado en el filesystem real (10 TiB): en este caso el límite del archivo es el inodo,
      no el disco.

Se tiene un filesystem UFS, con bloques de 4 KiB y punteros de 8 bytes, con un disco de 10 TiB. El
inodo está conformado con 10 punteros directos, 2 indirectos dobles y 2 indirectos triples.

- a) Indique el máximo espacio direccionable teórico y real.
- b) Indique el tamaño máximo teórico de un archivo.
