calculos:
  - enunciado: 'a) Tamaño máximo teórico y real del FS, y tamaño máximo de un archivo.'
    campos:
      - { etiqueta: 'FS teórico', respuesta: '2^74', unidad: B }
      - { etiqueta: 'FS real', respuesta: 1, unidad: TiB }
      - { etiqueta: 'Archivo máximo (exacto)', respuesta: 4227338, unidad: KiB }
    justificacion: |
      - **FS teórico:** `2^64 bloques × 2^10 B = 2^74 B`.
      - **FS real:** lo limita la partición → **1 TiB** (2<sup>40</sup> B).
      - **Archivo:** punteros por bloque `1 KiB / 8 B = 2^7 = 128`.

      | Punteros | Bloques de datos |
      | --- | --- |
      | 10 directos | 10 |
      | 2 indirectos simples | 2 × 128 = 256 |
      | 2 indirectos dobles | 2 × 128<sup>2</sup> = 32.768 |
      | 2 indirectos triples | 2 × 128<sup>3</sup> = 4.194.304 |
      | **Total** | **4.227.338** |

      `4.227.338 KiB ≈ 2 × 2^21 KiB = 2^32 B =` **4 GiB** aprox. (lo dominan los triples). Como
      entra en el FS real de 1 TiB, el archivo máximo real es el mismo.
  - enunciado: 'b) Bloques que hay que leer para acceder al byte 415.000 de un archivo.'
    campos:
      - { etiqueta: 'Bloque del archivo', respuesta: 405 }
      - { etiqueta: 'Bloques leídos', respuesta: 3, unidad: bloques }
    justificacion: |
      `415.000 / 1024 = 405,27` → bloque **405** del archivo.

      | Punteros | Bloques del archivo |
      | --- | --- |
      | 10 directos | 0 – 9 |
      | 1.er indirecto simple | 10 – 137 |
      | 2.º indirecto simple | 138 – 265 |
      | 1.er indirecto doble | 266 – 16.649 |

      El 405 cae en el **1.er indirecto doble**: se lee su bloque de punteros de 1.er nivel, el de
      2.º nivel que corresponde y el bloque de datos → **3 bloques**.
  - enunciado: 'c) Bloques ocupados por un archivo de 1 MiB.'
    campos:
      - { etiqueta: 'Bloques ocupados', respuesta: 1033, unidad: bloques }
    justificacion: |
      `1 MiB / 1 KiB = 1024` bloques de datos:

      - 10 por los **directos** → quedan 1014.
      - 256 por los **2 indirectos simples** + 2 BP → quedan 758.
      - 758 por el **1.er indirecto doble**: `758 / 128 = 5,9` → 6 BP de 2.º nivel + 1 BP de 1.er
        nivel.

      `1024 BD + 2 + 1 + 6 =` **1033 bloques**.
---

Dado un FS de tipo EXT2 formateado sobre una partición de 1 TiB que cuenta con punteros de 64 bits,
bloques de 1 KiB y cuyos inodos cuentan con 10 punteros directos, 2 punteros indirectos simples, 2
dobles y 2 triples.

Responda:

- a) ¿Cuál es el tamaño máximo teórico y real del FS? ¿Y de un archivo?
- b) ¿Cuántos bloques deben ser leídos para acceder al byte 415.000 de un archivo?
- c) ¿Cuántos bloques serían ocupados para almacenar un archivo de 1 MiB?
