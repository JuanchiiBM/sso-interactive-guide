calculos:
  - enunciado: 'a) Con clusters de 1 KiB.'
    campos:
      - { etiqueta: 'Espacio direccionable teórico', respuesta: 256, unidad: GiB }
      - { etiqueta: 'Espacio direccionable real', respuesta: 256, unidad: GiB }
      - { etiqueta: 'Archivo máximo teórico', respuesta: 256, unidad: GiB }
      - { etiqueta: 'Archivo máximo real', respuesta: 256, unidad: GiB }
    justificacion: |
      FAT32 usa **28 bits** de cada entrada para numerar clusters (los otros 4 están reservados):

      - **Teórico:** `2^28 × 1 KiB = 2^28 × 2^10 = 2^38 bytes = 256 GiB`.
      - **Real:** el mínimo entre el teórico y el disco: `min(256 GiB, 512 GiB) = 256 GiB`. La mitad
        del disco queda **sin direccionar**.
      - **Archivo:** en FAT un archivo puede usar todos los clusters del volumen, así que su máximo
        coincide con el del filesystem: 256 GiB teórico y real.
  - enunciado: 'b) Con clusters de 4 KiB.'
    campos:
      - { etiqueta: 'Espacio direccionable teórico', respuesta: 1024, unidad: GiB }
      - { etiqueta: 'Espacio direccionable real', respuesta: 512, unidad: GiB }
      - { etiqueta: 'Archivo máximo teórico', respuesta: 1024, unidad: GiB }
      - { etiqueta: 'Archivo máximo real', respuesta: 512, unidad: GiB }
    justificacion: |
      - **Teórico:** `2^28 × 4 KiB = 2^28 × 2^12 = 2^40 bytes = 1 TiB = 1024 GiB`.
      - **Real:** `min(1 TiB, 512 GiB) = 512 GiB`: ahora el límite es el disco, y se usan solo
        `2^39 / 2^12 = 2^27` de las 2<sup>28</sup> entradas posibles.
      - **Archivo:** igual que el filesystem: 1 TiB teórico, 512 GiB real.

      Cuadruplicar el cluster cuadruplica el teórico. Con 2 KiB (2<sup>28</sup> × 2 KiB = 512 GiB)
      ya alcanzaría para todo el disco, con menos fragmentación interna.
---

Suponga que formatea un disco de 512 GiB con FAT32, indique el máximo espacio direccionable y el
tamaño máximo de un archivo (en ambos casos, tanto el teórico y el real) con las siguientes
configuraciones:

- a) Con clusters de 1 KiB
- b) Con clusters de 4 KiB

> **Nota:** se sigue el criterio de las resoluciones de parciales: en FAT el tamaño máximo de un
> archivo se toma igual al del filesystem. En la implementación real, el campo "tamaño" de la entrada
> de directorio (4 bytes) lo limita a 4 GiB.
