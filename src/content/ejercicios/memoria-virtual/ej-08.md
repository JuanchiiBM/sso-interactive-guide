calculos:
  - enunciado: 'a) Dirección física de cada dirección lógica de A (hexadecimal) y frame asignado.'
    campos:
      - { etiqueta: '`A1012222h`', respuesta: '000A2222', base: 16 }
      - { etiqueta: '`030110A1h`', respuesta: '001510A1', base: 16 }
      - { etiqueta: '`03030000h`', respuesta: '000B0000', base: 16 }
      - { etiqueta: Page faults, respuesta: 1, unidad: PF }
      - { etiqueta: Frame asignado por el PF, respuesta: '0015', base: 16 }
    justificacion: |
      La tabla de 1er nivel tiene 256 entradas → **8 bits** para el 1er nivel y, por enunciado, otros
      **8** para el 2do. La DL de 32 bits queda `nivel 1 (8) | nivel 2 (8) | offset (16)`: los
      primeros 4 dígitos hexa son la página y los últimos 4, el offset.

      1. **A1012222h** → página A101. La TLB tiene `A101 → 000A` **de A**: **hit**, sin PF y sin
         acceder a las tablas. DF = **000A2222h** (frame 10).
      2. **030110A1h** → página 0301. La TLB tiene la 0301 pero **de B**: miss. TP1[03] → tabla en
         FFF30000h; TP2[01] → presencia 0: **page fault**. El bitmap da como primer libre el
         **0015h** (21) → DF = **001510A1h**. Se agrega `0301 → 0015, A` a la TLB y el bit 0015 del
         bitmap pasa a 1.
      3. **03030000h** → página 0303: miss. TP1[03] → FFF30000h; TP2[03] = **000B**, presente. DF =
         **000B0000h** (frame 11). Se agrega `0303 → 000B, A` a la TLB.

      Accesos a memoria: el 1 no lee tablas (solo el dato); el 2 y el 3 leen TP1 y TP2 y después el
      dato (el 2, además, reintenta la traducción tras el PF).
preguntas:
  - enunciado: 'b) ¿Qué habría cambiado si la TLB no tuviera la columna "Proceso"?'
    opciones:
      - texto: 'Nada: la TLB guarda páginas y frames, el proceso no influye en la traducción'
        explicacion: 'Sí influye: la página 0301 existe en la TLB, pero es de B.'
      - texto: 'La 2da traducción: A tomaría la entrada 0301 → 00AA de B y accedería a memoria de otro proceso (00AA10A1h)'
        explicacion: Correcta.
      - texto: 'La 1ra traducción: la A101 daría miss y habría que leer las tablas'
        explicacion: 'Sin la columna, la entrada A101 sigue estando y daría hit igual.'
      - texto: 'La 3ra traducción: la 0303 daría page fault'
        explicacion: 'La 0303 no está en la TLB con o sin la columna: se resuelve con las tablas.'
    correcta: 1
    justificacion: |
      La columna "Proceso" (ASID) es lo que permite tener en la TLB entradas de varios procesos a la
      vez. Sin ella, la búsqueda de la página 0301 daría **hit** con la entrada de B y A obtendría
      **00AA10A1h**: una dirección de la memoria de otro proceso. Por eso, una TLB sin ASID tiene
      que **vaciarse en cada cambio de proceso**.

Un sistema utiliza **paginación jerárquica**, dedicando igual cantidad de bits para sus dos
niveles. Se sabe que el sistema posee el bitmap en el estado indicado debajo, y realiza una
asignación ascendente por cada pedido encontrando el primero libre. La tabla de páginas del primer
nivel tiene 256 entradas. En este momento comienza a ejecutar el proceso A.

| 01 | FFG20000h |
| 02 | FFF10000h |
| 03 | FFF30000h |
| 04 | FFF50000h |
| … | … |
