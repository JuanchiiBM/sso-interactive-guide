Se dispone de una RAM con capacidad de 128 KiB, la cual tiene definido como tamaño de página
16 KiB. Se desea conocer el algoritmo en el que se basan para hacer el reemplazo de páginas,
sabiendo que el método de sustitución es **global** y la asignación de frames es **dinámica**.
Para ello, disponemos de la siguiente información:

Notas:

- F: número de frame; P: bit de presencia; U: bit de uso; M: bit de modificado; TS: timestamp
  (último instante de referencia).
- Para realizar los reemplazos, los frames son ordenados de forma ascendente (0 a n).
- Las direcciones lógicas tienen un tamaño de 20 bits.
- La última referencia realizada fue realizada por el Proceso C (PC) a la dirección 045B6h
  (lectura) generando la dirección física 0C5B6h.
- También se sabe que solamente se hicieron 4 referencias adicionales, siendo estas las siguientes:
  - PA – 00AEFh (escritura) generando la dirección física 10AEFh.
  - PC – 17A1Ch (escritura) generando la dirección física 00A1Ch.
  - PB – 13778h (escritura) generando la dirección física 17778h.
  - PA – 095F1h (lectura) generando la dirección física 095F1h.

a) ¿Cuál/es podría ser el algoritmo de reemplazo utilizado? Justifique.

b) Mencione la cantidad de Page Faults y Accesos a Disco que podrían haber generado las 4
referencias adicionales.
