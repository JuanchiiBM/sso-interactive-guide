nota: |
  Si la página no tiene frame asignado, no está en memoria: la dirección física todavía no existe y
  se produce un **page fault**. En ese caso marcá **Fault**.
calculos:
  - enunciado: '¿Cuáles son las direcciones físicas de las siguientes direcciones virtuales (en decimal)?'
    fault: true
    campos:
      - { etiqueta: '`0`', respuesta: 3072 }
      - { etiqueta: '`3728`', respuesta: fault }
      - { etiqueta: '`1024`', respuesta: 1024 }
      - { etiqueta: '`1025`', respuesta: 1025 }
      - { etiqueta: '`4099`', respuesta: 2051 }
      - { etiqueta: '`7800`', respuesta: fault }
    justificacion: |
      Con páginas de 1024 bytes:

      - **página** = dirección ÷ 1024 (división entera);
      - **desplazamiento** = dirección mod 1024;
      - **física** = frame × 1024 + desplazamiento.

      | Virtual | Página | Desplaz. | Frame | Física |
      | --- | --- | --- | --- | --- |
      | 0 | 0 | 0 | 3 | 3 × 1024 + 0 = **3072** |
      | 3728 | 3 | 656 | — | **page fault** |
      | 1024 | 1 | 0 | 1 | 1 × 1024 + 0 = **1024** |
      | 1025 | 1 | 1 | 1 | 1 × 1024 + 1 = **1025** |
      | 4099 | 4 | 3 | 2 | 2 × 1024 + 3 = **2051** |
      | 7800 | 7 | 632 | — | **page fault** |

      Las páginas 3 y 7 no tienen frame: el SO tiene que traerlas de disco. La memoria física tiene
      solo 4 frames y están todos ocupados (por las páginas 0, 1, 4 y 6), así que para cargarlas va a
      tener que **reemplazar** alguna.

      En 1024 y 1025 la física coincide con la virtual porque la página 1 está justo en el frame 1.

Un esquema de memoria virtual tiene un tamaño de página de 1024 bytes y la memoria física tiene 4
marcos de página. La tabla de páginas de un proceso es:

| Página virtual | Marco |
| -------------- | ----- |
| 0              | 3     |
| 1              | 1     |
| 2              | –     |
| 3              | –     |
| 4              | 2     |
| 5              | –     |
| 6              | 0     |
| 7              | –     |

¿Cuáles son las direcciones físicas de las siguientes direcciones virtuales (expresadas en
decimal): 0, 3728, 1024, 1025, 4099, 7800?
