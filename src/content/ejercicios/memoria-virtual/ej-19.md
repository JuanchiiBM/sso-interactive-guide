Indique la cantidad de accesos a disco (indicando el motivo) y el estado de la memoria del proceso
luego de cada referencia para la siguiente traza de referencias (**escrituras**) de un proceso:
**122881, 98427, 93112 y 156191** (en decimal), el cual ejecuta en un sistema con paginación y
memoria virtual, con asignación local y fija de 4 frames.

**Conjunto residente inicial**

| Pág. | U   | M   |     |
| ---- | --- | --- | --- |
| 28   | 0   | 1   |     |
| 16   | 0   | 1   |     |
| 09   | 1   | 1   | ←   |
| 12   | 1   | 0   |     |

Notas:

- El algoritmo de reemplazo es clock mejorado.
- Las direcciones lógicas son de 20 bits, y los procesos no pueden tener más de 128 páginas.
