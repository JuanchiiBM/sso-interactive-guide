  - enunciado: '¿Cuál sería el tamaño mínimo de la dirección para que un proceso pueda direccionar hasta 1 MiB? Indicá también cómo se reparte entre página y desplazamiento.'
    campos:
      - { etiqueta: 'Dirección', respuesta: 20, unidad: bits }
      - { etiqueta: 'Número de página', respuesta: 7, unidad: bits }
      - { etiqueta: 'Desplazamiento', respuesta: 13, unidad: bits }
    justificacion: |
      Con **memoria virtual**, el espacio lógico de un proceso **no** está limitado por la RAM: las
      páginas que no entran se quedan en disco y se traen cuando se usan. Por eso los 128 KiB de RAM
      no influyen en la respuesta.

      - **Dirección:** 1 MiB = 2<sup>20</sup> bytes → **20 bits**.
      - **Desplazamiento:** páginas de 8 KiB = 2<sup>13</sup> bytes → **13 bits**.
      - **Página:** 20 − 13 = **7 bits**, o sea 2<sup>7</sup> = 128 páginas de 8 KiB = 1 MiB.

      La RAM sí define la dirección **física**: 128 KiB = 2<sup>17</sup> → 17 bits, de los cuales 4
      son de frame (16 frames). La dirección lógica (20 bits) es **mayor** que la física (17 bits),
      algo que sin memoria virtual no podría pasar (ver Memoria real, Ej. 1).
