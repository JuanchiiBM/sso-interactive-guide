    campos:

      - { etiqueta: Página referenciada por A, respuesta: 11 }
      - { etiqueta: Frame usado, respuesta: 20 }
    justificacion: |
      Fragmentación interna máxima de casi 1 MiB → páginas de **1 MiB** = `2^20` → **20 bits de
      offset** (5 dígitos hexa). La DL de 32 bits deja 12 bits de página.

      - DL `00BB1233h` = `00B | B1233` → página **0x00B = 11**, que A no tiene presente: **PF**.
      - DF `14B1233h` = `14 | B1233` → frame **0x14 = 20**.

      El frame 20 lo tenía la **página 2 de B** (TUR 100, TC 100, U 0, M 1): esa fue la víctima.
preguntas:
  - enunciado: '¿Qué algoritmos de sustitución podrían haber elegido esa víctima?'
    opciones:
      - texto: 'FIFO y LRU'
        explicacion: 'FIFO saca la cargada hace más tiempo: la página 0 de A (TC 50), no la 2 de B (TC 100).'
      - texto: 'Solo LRU'
        explicacion: 'Clock también puede, si el puntero estaba en el frame 20.'
      - texto: 'LRU y Clock'
        explicacion: Correcta.
      - texto: 'Clock y Clock mejorado'
        explicacion: 'Clock mejorado habría elegido la página 0 de A, que es (0,0), antes que una (0,1).'
    correcta: 2
    justificacion: |
      Páginas presentes (frame, TUR, TC, U, M): A0 (30, 105, 50, 0, 0) · A2 (40, 200, 90, 1, 0) ·
      A3 (50, 300, 95, 1, 1) · B2 (20, 100, 100, 0, 1). La víctima fue **B2**.

      - **FIFO: no.** La de menor TC es A0 (50).
      - **LRU: sí.** La de menor TUR es B2 (100).
      - **Clock: sí.** B2 tiene U = 0; con los frames en orden 20, 30, 40, 50 y el puntero en el 20,

      - **Clock mejorado: no.** En la 1ra vuelta busca (0,0) y A0 lo es: la elegiría siempre antes
        que B2, que es (0,1).

Se posee un sistema de paginación bajo demanda con asignación **dinámica** y sustitución **global**
de frames. Los únicos frames utilizables por procesos de usuario son: 20, 30, 40 y 50. Las DL son
de 32 bits y el máximo de fragmentación interna por proceso es de casi 1 MiB. De los procesos, se
conoce el estado de las tablas de páginas en un determinado instante:

| Pág. | Proceso A | | | | | | Proceso B | | | | | |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| | **F** | **P** | **TUR** | **TC** | **U** | **M** | **F** | **P** | **TUR** | **TC** | **U** | **M** |
| 0 | 30 | 1 | 105 | 50 | 0 | 0 | 30 | 0 | 5 | 5 | 0 | 0 |
| 1 | 20 | 0 | 20 | 10 | 0 | 0 | 20 | 0 | 92 | 30 | 0 | 0 |
| 2 | 40 | 1 | 200 | 90 | 1 | 0 | 20 | 1 | 100 | 100 | 0 | 1 |
| 3 | 50 | 1 | 300 | 95 | 1 | 1 | 50 | 0 | 33 | 20 | 0 | 0 |
| … | | | | | | | | | | | | |

TUR = tiempo de última referencia, el instante en que la página fue referenciada por última vez.
TC = tiempo de carga, el instante en que la página fue cargada a memoria por última vez.

Se sabe que, inmediatamente posterior a dicho instante, el Proceso A hace referencia a su DL
**00BB1233h**, la cual genera la DF **14B1233h**.

Indique qué algoritmo de sustitución se podría estar utilizando, justificando tanto los que
apliquen como los descartados. Considere que los datos provistos en las TPs deben ser utilizados
para los algoritmos que apliquen.
