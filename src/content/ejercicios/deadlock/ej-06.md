Se tienen 3 procesos, que se encuentran sincronizados con la intención de imprimir CASACASACASA… indefinidamente.

<div class="codigo-columnas">

**Proceso C**

```c
while(TRUE){
  wait(CS);
  wait(C);
  print("C");
  signal(A);
  signal(S);
}
```

**Proceso A**

```c
while(TRUE){
  wait(A);
  print("A");
  signal(CS);
}
```

**Proceso S**

```c
while(TRUE){
  wait(CS);
  wait(S);
  print("S");
  signal(A);
  signal(C);
}
```

</div>

**Semáforos: CS = 1, C = 1, A = 0, S = 0**

- a. Proponga una secuencia de ejecución de procesos en la que ocurriría deadlock.
- b. Proponga alguna forma para evitar el deadlock, basándose en las alternativas que da la estrategia de Prevención (sin modificar el código).
- c. Proponga algún cambio en el pseudocódigo para que no puedan ocurrir deadlocks entre estos procesos.
