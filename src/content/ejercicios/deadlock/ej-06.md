  solucion: |
    semaphore CS = 1, C = 1, A = 0, S = 0;

    void C() {
      while(TRUE){
        wait(C);
        wait(CS);
        print("C");
        signal(A);
        signal(S);
      }
    }

    void A() {
      while(TRUE){
        wait(A);
        print("A");
        signal(CS);
      }
    }

    void S() {
      while(TRUE){
        wait(S);
        wait(CS);
        print("S");
        signal(A);
        signal(C);
      }
    }
  justificacion: |
    **Por qué se traba el original:** C y S hacen `wait(CS)` **antes** de esperar su turno. Después de
    "CA", A devuelve `CS`; si C lo toma primero, se queda esperando `C` (que vale 0) **con `CS`
    retenido**, y S queda esperando `CS`. A espera `A`. Nadie puede avanzar: hay **retención y espera**
    y **espera circular** sobre `CS`.

    **Corrección:** esperar primero el semáforo de turno (`C` o `S`) y recién después `CS`. Así solo
    toma `CS` el proceso al que efectivamente le toca, y se rompe la condición de retención y espera.
    Es la regla de la cátedra: **el orden de los `wait` importa**.
