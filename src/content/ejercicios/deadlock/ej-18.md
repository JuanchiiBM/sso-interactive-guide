    procesos: P1, P2, P3

    P2 -> B
    P1 -> C
    resaltar-ciclo

    P3 se bloquea.

Se tiene un sistema en que se ejecutan 3 procesos concurrentemente. La planificación se realiza mediante un algoritmo **por prioridades con desalojo** (a menor número, mayor prioridad).

Semáforos: `A = 1, B = 1, C = 1`. Variables compartidas: `a, b, c`. **Cada línea de pseudocódigo consume dos unidades de tiempo** y las llamadas al sistema `wait` y `signal` se consideran **atómicas**.

<div class="codigo-columnas">

**Proceso 1 (prioridad 10)**

```c
WAIT(A)
WAIT(B)
WAIT(C)
a = b + c
SIGNAL(A)
SIGNAL(B)
SIGNAL(C)
```

**Proceso 2 (prioridad 5)**

```c
WAIT(C)
WAIT(B)
c = c + b
SIGNAL(C)
SIGNAL(B)
```

**Proceso 3 (prioridad 1)**

```c
WAIT(B)
WAIT(A)
a++
b++
SIGNAL(B)
SIGNAL(A)
```

</div>

Instantes de llegada a Ready: **P1 → t0, P3 → t3, P2 → t5**.

a) Realice un diagrama de Gantt para representar la ejecución de los procesos en dicho sistema.

b) Si el sistema queda en deadlock, realice el diagrama de asignación de recursos resultante, indicando cuáles participan del mismo. Si no se genera deadlock, proponga un cambio en el pseudocódigo para que ocurra y demuestre cómo ocurriría.
