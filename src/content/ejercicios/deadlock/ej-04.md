Demuestre que el siguiente conjunto de procesos podría caer en Deadlock **(utilice el grafo de asignación de recursos)**, se sabe que para poder tomar mate un proceso necesita todos los recursos, y sólo existe 1 mate y 1 termo.
¿Cómo lo resolvería?

- a. Proponga una solución utilizando solamente semáforos
- b. Proponga una solución aplicando el mecanismo de Prevención

<div class="codigo-columnas">

**Proceso A**

```c
while(TRUE){
  mate = agarrar_mate()
  termo = agarrar_termo()
  preparar(mate)
  cebar(mate,termo)
}
```

**Proceso B**

```c
while(TRUE){
  termo = agarrar_termo()
  mate = agarrar_mate()
  preparar(mate)
  cebar(mate,termo)
}
```

</div>

Nota: las funciones **agarrar_mate** y **agarrar_termo** son bloqueantes si el recurso no está disponible.
