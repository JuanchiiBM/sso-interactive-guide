Existen 2 procesos que se encuentran en Ready. Los recursos que se solicitan y las instancias disponibles son: **1 teclado, 1 mouse y 2 monitores**.

Ambos procesos comparten una biblioteca de manejo de recursos que provee las funciones `recursos_disponibles`, `usar_recurso` y `liberar_recursos`. `recursos_disponibles` consulta una variable global `RECURSOS_ACTUALES` y retorna true si están todos disponibles. Tanto `usar_recurso` como `liberar_recursos` modifican `RECURSOS_ACTUALES`. `usar_recurso` es **bloqueante** si el recurso no se encuentra disponible.

<div class="codigo-columnas">

**Proceso 1**

```c
while (true) {
  char* rec_a_usar = [TECLADO, MOUSE];
  if (recursos_disponibles(rec_a_usar)) {
    usar_recurso(rec_a_usar[0]);
    usar_recurso(rec_a_usar[1]);
    liberar_recursos(rec_a_usar);
  }
}
```

**Proceso 2**

```c
while (true) {
  char* rec_a_usar = [MOUSE, MONITOR, TECLADO];
  if (recursos_disponibles(rec_a_usar)) {
    usar_recurso(rec_a_usar[0]);
    usar_recurso(rec_a_usar[1]);
    usar_recurso(rec_a_usar[2]);
    liberar_recursos(rec_a_usar);
  }
}
```

</div>
