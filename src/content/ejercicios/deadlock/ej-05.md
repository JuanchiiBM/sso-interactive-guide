Estos dos procesos ejecutan sus tareas hasta finalizar, ¿qué problema puede identificarse?

<div class="codigo-columnas">

**Homero**

```c
while(TRUE){
  respuesta = preguntar("¿Ya llegamos a la India?")
  if(respuesta == "Mmmm Ya!"){
    exit()
  }
}
```

**Apu**

```c
estamos_en_india = false
while(TRUE){
  if(estamos_en_india){
    responder("Mmmm Ya!")
    exit()
  }else{
    responder("No")
  }
}
```

</div>

Nota: preguntar y responder son funciones NO bloqueantes.
