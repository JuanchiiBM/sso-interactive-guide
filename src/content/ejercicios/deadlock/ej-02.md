Se tienen tres procesos P1, P2 y P3 y tres recursos R1, R2 y R3, todos con una única instancia.
El estado es:

- R1 → P1
- P1 → R2
- R2 → P2
- P2 → R1
- R3 → P3

P3 no solicita ningún otro recurso y puede finalizar normalmente.
Realiza el grafo e indica si se produce algún deadlock. En caso afirmativo, ¿qué proceso y qué recursos involucra? En caso contrario, indica cómo van finalizando los procesos.
