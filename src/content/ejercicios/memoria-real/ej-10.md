  - enunciado: 'a) Reconstruí la tabla de segmentos del proceso A (en hexadecimal).'
    tabla:
      columnas: [Segmento, Base, Tamaño]
      filas:
        - ['0', { respuesta: '9000', base: 16 }, { respuesta: '2000', base: 16 }]
        - ['1', { respuesta: 'D000', base: 16 }, { respuesta: '3000', base: 16 }]
        - ['2', { respuesta: '0', base: 16 }, { respuesta: '2000', base: 16 }]
    justificacion: |
      16 bits con 64 KiB de memoria: **2 bits de segmento** (hasta 4 segmentos) y **14 bits de
      offset** (segmentos de hasta 16 KiB).

      - `9FFFh = 10 01 1111 1111 1111` → segmento **2**, offset 1FFFh. Es la **última** dirección
        válida, así que el segmento mide 1FFFh + 1 = **2000h** (8 KiB). Da DF 1FFFh, entonces la
        base es 1FFFh − 1FFFh = **0000h**.
      - `0A98h` → segmento **0**, offset A98h; DF 9A98h → base = 9A98h − A98h = **9000h**. Mide
        8 KiB = **2000h** (dato).
      - `51FAh = 01 01 0001 1111 1010` → segmento **1**, offset 11FAh; DF E1FAh → base =
        E1FAh − 11FAh = **D000h**. Está al final de la memoria (10000h), así que mide
        10000h − D000h = **3000h** (12 KiB).

      Memoria: A.S2 `[0, 2000h)`, **libre** `[2000h, 9000h)` (28 KiB), A.S0 `[9000h, B000h)`,
      **libre** `[B000h, D000h)` (8 KiB), A.S1 `[D000h, 10000h)`.

    tabla:
      columnas: [Segmento, Base, Tamaño]
      filas:
        - ['0', { respuesta: '2000', base: 16 }, { respuesta: '4000', base: 16 }]
        - ['1', { respuesta: '0', base: 16 }, { respuesta: '2000', base: 16 }]
        - ['2', { respuesta: '6000', base: 16 }, { respuesta: '3000', base: 16 }]
        - ['3', { respuesta: '9000', base: 16 }, { respuesta: '4000', base: 16 }]
        - ['Hueco libre', { respuesta: 'D000', base: 16 }, { respuesta: '3000', base: 16 }]
    justificacion: |
      1. **B.S0 (16 KiB):** el único hueco donde entra es el de 28 KiB → base **2000h**. Queda un
         hueco de 12 KiB en `[6000h, 9000h)`.
      2. **B.S1 (8 KiB):** huecos de 12 KiB y 8 KiB; Best Fit elige el de 8 KiB, que encaja justo
         → base **B000h**.
      3. **B.S2 (12 KiB):** el hueco de 12 KiB en **6000h**, justo. La memoria queda **llena**.
      4. **A termina:** libera `[0, 2000h)` (8 KiB), `[9000h, B000h)` (8 KiB) y `[D000h, 10000h)`
         (12 KiB). Son 28 KiB pero separados.
      5. **B.S3 (16 KiB):** no entra en ningún hueco aunque la suma alcanza → hay que **compactar**.
         Alcanza con mover **un solo segmento**: B.S1 (8 KiB, en B000h) al hueco del principio
         (base **0000h**). Así `[9000h, 10000h)` queda libre y contiguo (28 KiB), y S3 va en
         **9000h**. Queda un único hueco: `[D000h, 10000h)`, **12 KiB**.

      | Desde | Hasta | Contenido |
      | --- | --- | --- |
      | 0000h | 2000h | B.S1 |
      | 2000h | 6000h | B.S0 |
      | 6000h | 9000h | B.S2 |
      | 9000h | D000h | B.S3 |
      | D000h | 10000h | **libre (12 KiB)** |

      (Mover B.S2 al final también libera lugar para S3 moviendo un solo segmento, pero deja dos
      huecos; por eso la nota pide el que deja uno solo, que es el de la resolución oficial.)

      Es **fragmentación externa**: los 28 KiB libres están repartidos en huecos de 8, 8 y 12 KiB.
      La segmentación pura necesita cada segmento contiguo, así que la única salida (sin terminar

Se dispone de un sistema con direcciones de 16 bits y una memoria física de 64 KiB administrado
bajo un esquema de **segmentación pura** con algoritmo de asignación de huecos **best-fit**. Se
encuentra actualmente ejecutando 1 proceso A con 3 segmentos (0, 1 y 2) del cual solamente se sabe
que:

- La dirección lógica 9FFFh es la última dirección válida de su Segmento 2 y genera la dirección
  física 1FFFh.
- La dirección lógica 0A98h genera la dirección física 9A98h.
- El tamaño del Segmento 0 es 8 KiB.
- La dirección lógica 51FAh genera la dirección física E1FAh.
- El Segmento 1 está situado al final de la memoria física.

a) Reconstruya la tabla de segmentos del proceso A, indicando los valores base y tamaño/límite
para cada segmento.

Luego, se realizan en orden las siguientes peticiones al sistema operativo:

- Se inicializa un Proceso B con un Segmento 0 de 16 KiB. Luego, crea un Segmento 1 de 8 KiB y un
  Segmento 2 de 12 KiB.
- El proceso A finaliza.
- El proceso B crea un segmento 3 de 16 KiB.

b) Muestre el estado final de las tablas de segmentos, así como de huecos libres en la memoria.
