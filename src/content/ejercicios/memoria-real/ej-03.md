tema: parcial-2/memoria-real
fuente: { guia: 'Guía de Ejercicios – Memoria (2016, Rev. 1) · Ej. 3', numero: 3 }
tipo: practico
dificultad: facil
tags: [segmentacion, traduccion]
nota: |
  La tabla da el **largo** (tamaño) de cada segmento, no el **límite**. En las PPTs de la cátedra el
  límite es la **dirección final** del segmento y se compara contra la dirección física. Con el
  largo, la comparación se hace contra el **desplazamiento**: es válido si `desplazamiento < largo`.
calculos:
  - enunciado: 'Calculá la dirección física de cada dirección lógica (segmento, desplazamiento).'
    fault: true
    campos:
      - { etiqueta: '`(0, 430)`', respuesta: 649 }
      - { etiqueta: '`(1, 10)`', respuesta: 2310 }
      - { etiqueta: '`(2, 500)`', respuesta: fault }
    justificacion: |
      Para cada dirección: primero **validar** el desplazamiento contra el largo del segmento, y
      solo si entra, **traducir** con base + desplazamiento.

      | Lógica | Validación | Física |
      | --- | --- | --- |
      | (0, 430) | 430 < 600 ✓ | 219 + 430 = **649** |
      | (1, 10) | 10 < 14 ✓ | 2300 + 10 = **2310** |
      | (2, 500) | 500 ≥ 100 ✗ | **segmentation fault** |

      En (2, 500) la suma 90 + 500 = 590 **nunca se hace**: la MMU detecta que el desplazamiento se
      sale del segmento, lanza una interrupción y el SO responde con segmentation fault. Si se
      hiciera, el proceso accedería a memoria que no es de ese segmento.
---

Dada la siguiente tabla de segmentos, determine las direcciones físicas:

| Segmento | Base | Largo |
| -------- | ---- | ----- |
| 0        | 219  | 600   |
| 1        | 2300 | 14    |
| 2        | 90   | 100   |
| 3        | 1327 | 580   |

| Dirección lógica | Dirección física |
| ---------------- | ---------------- |
| 0, 430           |                  |
| 1, 10            |                  |
| 2, 500           |                  |
