En un sistema que utiliza segmentación sin memoria virtual, con una memoria de 64 KiB, hay solo
dos procesos ejecutando, con las siguientes tablas de segmentos:

| Proceso 1 | | Proceso 2 | |
| --- | --- | --- | --- |
| **Base** | **Tamaño** | **Base** | **Tamaño** |
| 0 | 8192 | 59392 | 6144 |
| 34816 | 8192 | 28672 | 6144 |
| 12288 | 14336 | 49152 | 6144 |
| – | – | – | – |

Si al proceso 1 se le asignara un nuevo segmento de 4096 B, indique cómo quedaría su tabla de
segmentos si se utiliza como algoritmo de asignación **Best Fit**.
